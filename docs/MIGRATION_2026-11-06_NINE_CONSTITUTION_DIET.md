# 九种体质食养完整覆盖专项迁移（2026-11-06）

> 本文是公开工程迁移记录，不含私有知识库正文、健康记录或密钥。
> 决策来源：项目所有者进一步明确“目标是让知识库承担九种体质食养的完整覆盖”。本次扩展在食疗核心库基础上实施，不以疾病指南证型冒充体质，不以旧自定义映射补齐类别。

## 1. 覆盖定义

本次“完整覆盖”是指：

| 验收项 | 结果 |
|---|---|
| 九种体质均有正式来源的食养原则 | 9／9，来自 DB23/T 3701—2024 第 6.3.3 条 |
| 九种体质均有明确的宜食、少食或禁忌边界 | 9／9；平和质以膳食平衡、不轻易进补为主 |
| 八种偏颇体质至少有一条可核验药膳示例 | 8／8，来自天津市卫生健康委员会公开页面 |
| 每条药膳均有材料、制法和来源定位 | 8／8，未补写原文没有的每日频次或长期疗程 |
| 不把体质映射为六经、六病或方药 | 已落实；体质食养与方证、疾病指南分开 |
| 分类库与完整综合源库结果一致 | 50 组实际候选差分全部一致 |

完整覆盖不等于九种体质都必须有药膳。平和质按来源采用平衡膳食和“不轻易进补”，不为了形式统一而造方。完整覆盖也不等于完成临床有效性验证或适合每位使用者。

## 2. 实际资料与分工

### 九类食养原则

采用正式地方标准 DB23/T 3701—2024《中医医养结合服务规范》第 6.3.3 条，正式文本第 8–9 页。该标准于 2024-06-13 发布、2024-07-12 实施，覆盖平和、气虚、阳虚、阴虚、痰湿、湿热、血瘀、气郁、特禀九类食养原则。

原标准服务于中医医养结合机构。本库保留这一来源场景，不把机构服务条款当作面向任何个人的自动处方；体质名称只用于资料归类，不改变本系统体质判定、六经辨证和红线规则。

### 八类药膳示例

采用天津市卫生健康委员会 2021-08-30 发布的《平和质、气虚质、阳虚质……不同体质适合不同药膳，这么吃才健康！》，页面注明来源“中国中医、中国中医药报”。气虚、阳虚、阴虚、痰湿、湿热、血瘀、气郁、特禀各选一条，分别为参芪鹌鹑汤、枸杞炖羊肉、乌鸡汤、荷叶粥、薏米绿豆汤、山楂红糖水、杞瑰茶、乌梅粥。

每条保留原始材料、制作方法及“来源所述功效”。来源功效不等于系统承诺预防或治疗效果；未写每日频次时不补写。含药材、益母草或用于特禀质的条目，必须同时保留医师审核、过敏原回避和正规诊疗提示。

### 交叉参考但未泛化的资料

DB44/T 2724—2025《中医体质膳食模式体重管理技术规范》已核验正式 PDF 和九类条款。它只适用于成年（≥18 岁）超重或肥胖症人群的医疗机构体重管理，本库不将其热量或食谱泛化为所有使用者建议。

此前取得的《中医药膳学》《中医食疗学》仍只有书目与目录，没有用于本次条目生成。达州《中医体质辨识管理与服务规范》下载件标为征求意见稿，未作为正式标准采用。

## 3. 库结构与报告行为

新增 `constitution-diet-principles.md` 和 `constitution-diet-examples.md` 后，食疗库共有 8 份可检索正文，含 41 条食养方及 9 条体质原则。每条内容以完整 `食疗资料｜…` 段落返回，包含来源、适用条件和项目边界。

- 九类原则均标注 DB23/T 3701—2024 的具体条款号。
- 八种偏颇体质的示例与原则使用相同体质名，可联合检索；平和质只保留原则。
- 报告提示词允许使用有明确体质来源的候选，继续禁止无出处体质映射、食疗化经方及跨条拼接数量。
- 既有 `_diet_output_error()` 同时适用于“体质：方名”格式，可核对全名或方名短称及同条原始数量；特禀质食养不得替代过敏原回避、评估或必要治疗。
- 本地速览仍只提供安全边界，不根据四证聚类自动判定体质或选择药膳。

本次扩展前，官方资料核心库另存于 `.kb-reset-backup-diet-official-core-20261106/`；最初旧库备份仍为 `.kb-reset-backup-diet-rebuild-20261106-83b41fcd66/`。两阶段备份均不进入 Git。

## 4. 验证

- 九类原则逐条核对正式标准条款号、原则关键词和食材实例；八条药膳的材料、制法、功效共 24 处通过卫健委原文归一化比对。
- 当前库逐体质检索：八种偏颇体质均返回“原则＋药膳示例”，平和质返回食养原则。
- 分类专用库与完整综合源包在旧别名、新食养资料、九类体质及药膳名称等 50 组实际候选比较中全部一致。
- 新增“体质：方名”与原始数量对应关系回归；同源数量可保存，跨体质候选不能证明数量。
- 专用 ZIP 含 11 个文件、8 份可检索 Markdown；综合 ZIP 含 17 个文件、14 份综合区可检索 Markdown，并保留三个专用子库。6 份正式 PDF 与 1 份卫健委网页快照均记录 SHA-256。

- 独立数据目录、知识库副本和 Chrome 个人资料下，以模拟模型逐类完成 9 次真实报告 POST 与详情页验收，72 项页面断言全部通过；9 张截图逐张复核，药材及过敏提示按原始分辨率复核。桌面与 390 像素窄屏无横向溢出，JavaScript 异常为 0；真实记录和当前知识库前后哈希不变，临时服务和浏览器均已关闭。

全量测试与治理结果写入 v1.20.24 更新日志。工程验收不替代真实模型人工复核、医学标定、个体适用性或临床疗效评估。
