## 4. 多进程缺陷与修复

### 配置丢失更新

两个进程同步导入不同类别时，旧实现均返回成功，但其中一类最终未配置，副本却存在。根因是 `.env` 只在替换时加锁，未保护完整读—改—写—回读，知识库事务也缺少跨进程配置锁。

- `web/envfile.py` 复用 `io_utils.write_lock` 覆盖完整临界区。
- `web/kb_routes.py` 的模式、导入和重置事务共用同一配置锁，回滚也不会覆盖另一进程的后续更新。
- 新增真实 spawn 双进程回归；修复后两个导入请求均为 HTTP 200，体质和食疗都为 `ready`。
- 同日并发报告仍为一个 HTTP 200、一个 HTTP 409；记录 JSON 有效，无临时文件残留。

### 非活动根展示

未配置/停用类别曾把被忽略的外部旧根显示为当前目录。`inspect_kb_categories()` 现将非活动根返回为空，不改变启用、检索或删除行为；真实浏览器已确认停用类别当前目录为空。
