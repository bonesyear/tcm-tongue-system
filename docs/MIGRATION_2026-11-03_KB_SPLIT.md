## 2. 配置与运行边界

完整知识库继续通过现有 `TCM_KB_ROOT` 提供。该变量应指向用户有权使用的私有目录；Grep、RAG 和默认别名词典共用该根，路径解析未改变。

```bash
# Linux / macOS 示例
export TCM_KB_ROOT=/absolute/path/to/private-kb

# Windows 请在系统环境变量或项目 .env 中配置绝对路径
# TCM_KB_ROOT=C:\private\knowledge_base
```

公开包不附带原知识库，未配置时检索按既有行为返回空结果或告警，不伪造引用。公开版与私有完整知识库的功能边界已明确，不宣称两者等效。
