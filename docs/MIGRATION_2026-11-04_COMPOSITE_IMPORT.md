# 综合知识库导入入口（v1.20.5）

**日期**：2026-11-04
**范围**：在设置页三个分类知识库卡片之后增加综合知识库导入入口，用于调试及保证兼容性。不附带知识库内容，不改变分类检索、医学规则或版权边界。

## 1. 页面与状态

- 新卡片标题为“综合知识库”，说明文字为“此功能用于调试及保证兼容性。”
- 支持上传包含多类 Markdown/YAML 的综合 ZIP，复用现有 `composite` 导入端点和 8 MiB 限制。
- 设置页显示综合库可用状态、当前目录及可检索 Markdown 数；未配置时目录为空。
- 综合包不能包含 `constitution/`、`diet/`、`formula/` 保留目录，替换综合副本时保留三类专用副本。
- 严格分类模式开启时，综合库不参与回退。

## 2. 上传后的状态同步

综合导入可能使三类都通过综合库回退为可用。仅更新综合卡片会让其他类别仍显示未配置，因此成功导入后刷新设置页，以当前配置重新计算全部状态。分类导入仍采用原有局部更新，不增加页面刷新。
