# B06 预警引擎与出处体系迁移说明（2026-10-26）

> 范围：共享文本分析、三态预警、19 条规则与出处、存储校验、提示词和 Web 展示。
> 本批不重做绝汗亡阴/亡阳分类，不调整医学阈值，不恢复舌色九档；不进入 B07
> 采集方式或 B08 医学权重签认。

## 1. 新接口与旧接口

`src/alerts.py` 提供：

- `evaluate_alert(rule_id, observations) -> AlertEvaluation`
- `evaluate_alerts(observations) -> dict[str, AlertEvaluation]`
- `danger_flags_for(observations, previous=None) -> dict`
- `alert_evaluation_map(observations)`：读取当前版本的存储评估，否则只读重算。

`AlertEvaluation` 包含：

| 字段 | 含义 |
|---|---|
| `rule_id` | 既有 19 个红线键之一 |
| `kind` | `screening` 或 `critical_rule` |
| `state` | `triggered`、`not_triggered`、`unknown` |
| `matched_clauses` | 已满足的条款标签 |
| `missing_clauses` | 未采集或不能判定的条款标签 |
| `evidence` | 条款 ID、来源路径、证据文本、状态和排除/否定原因 |
| `provenance` | 来源 ID、文件哈希、关键词、定位和短引文 |

`screening` 表示单项或部分证据需要复核，**不是确诊**；`critical_rule` 只在规则
所需证据齐全时成立。未采集、非空但不能判读或组合仍缺证据时，不得写成
`not_triggered`。必需条件明确不满足，或所有可选证据都明确不满足时，才可返回
`not_triggered`。部分已知证据仍保留在 `matched_clauses` 中。

`src/danger.py` 保留 `DANGER_FLAGS`、`DANGER_PATTERNS` 和 `detect_danger()`。
后者仅返回阳性规则键列表，**不能从空列表推断已完成排除**；新调用方需要三态时
应使用 `evaluate_alert(s)` 或 `danger_flags_for()`。

## 2. 共享文本分析

`src/text_analysis.py` 的 `find_term()` 返回 `matched / negated / excluded / missing`、
位置和原因。评分与预警共用此结果，不再维护两个否定窗口：

- 前后否定：无、不、未、没、并非、绝非、排除，以及“未见/不明显/阴性”等后置表达；
- 逗号、分号结束否定小句；“但/然而/却/而”等无标点转折开始新证据边界；
- “需与狐惑鉴别”属于鉴别比较，不是患者阳性；“镜面反光/反射”不是镜面舌；
- “非典型黄染”不把单独“非”当否定，全部出现位置都检查，避免首个否定吞掉后续阳性。

未命中在旧 `score*` 中仍返回 0，在新 `assess*` 中仍区分 unknown；本批没有调整
任何医学分值。旧报告、辨证结论、方剂和已有 `danger_flags` 不作为新证据自证；
中文部位名等真实观察输入仍保留。

## 3. 三个代表规则

### 戴阳

- `红如妆` 与 `面红如妆` 都可召回，修复封闭枚举与旧探测不契约。
- 单独红如妆：`kind=screening`，缺失手足厥逆；不是组合证。
- 红如妆＋手足厥逆：`kind=critical_rule`，两项均有证据。
- 仅手足厥冷：保留 `unknown` 和已知条款，但不单独拦截戴阳流程。
- 明确否定必要面色条件：可 `not_triggered`；未采集不能直接写未触发。

出处为《经方探源》L8333、L8833。

### 急性黄疸

巩膜黄染是必需项，皮肤黄如橘皮或明确黄疸语境至少满足一项：

- 只有眼部或皮肤线索：筛查，并列出缺失证据；
- 两项齐全：`critical_rule`；
- “善色/阳黄”不单独确立急重症，也不把已经观察到的颜色证据反向抹掉。

黄疸组合与语境依据固定教材 PDF p56、p58、p71、p88。没有新增颜色分值或阈值。

### 镜面舌

- 结构化 `coating_peeling=镜面` 或明确 `critical_signs=镜面舌`：优先进入危重规则；
- 自由文本“镜面/光剥无苔/光亮如镜”：仅筛查；
- 光学反光/反射和局部无苔不误报，未评估仍为 unknown。

依据固定教材 PDF p118。结构化证据优先于自由文本，避免重复文本降低证据等级。

## 4. 其余规则与出处

`DANGER_FLAGS`、`DANGER_PATTERNS`、`ALERT_RULES`、`DANGER_PROVENANCE` 键集合一致。
每条出处都包含 `source_id + source_sha256 + keyword + locator + quote`。

- 风痱：L2285；狐惑：L4236；阳明危重：L2822–2826；神昏冷汗：L8329；
  肤冷脉微：L8329、L4216；大肉已脱/大骨陷下：L3603。
- 舌强语謇：固定教材 p118；镜面及八种危重舌象：p117–118；
  苔焦黑干燥＋舌质干裂起刺：p112。
- `tongue_critical` 不再把“紫暗”写成必需条件，按教材组合评估。
- 组合规则缺少任一必要证据时只保留筛查/未知；未重新分类绝汗亡阴/亡阳。

出处台账同步见 `docs/VOCAB_PROVENANCE_2026-10-16.md` §八。固定《经方探源》
文件哈希已复核，关键原文已直接核读。教材继续使用同一哈希对应的 PDF 和既有
审查页码；本机仍无可用的页内 OCR 工具，未宣称重新完成教材全文 OCR。

## 5. 存储、校验与展示

形状 B 的新 `danger_flags` 包含：

```json
{
  "triggered": ["daiyang"],
  "not_triggered": ["mirror_tongue"],
  "unknown": ["acute_jaundice"],
  "evaluations": [
    {
      "rule_id": "daiyang",
      "kind": "screening",
      "state": "triggered",
      "matched_clauses": ["面红如妆"],
      "missing_clauses": ["手足厥逆"],
      "evidence": [],
      "provenance": []
    }
  ],
  "ruleset_version": "2026-10-26.b06.1"
}
```

示例省略了实际证据与出处内容；真实写入由 `danger_flags_for()` 生成。旧触发键
在重新分析/修正时按既有语义保留并集，未知不再补进 `not_triggered`。

形状 A 保留原 `{flag: {triggered, finding}}`，可另带 `state: "unknown"` 占位；
旧记录不批量迁移。形状 C 继续由 `DailyRecord` 归一。校验器检查三态列表、
评估 `rule_id/state/kind` 及形状 A 可选状态。

向导和修正流写入完整评估。弹层与详情页显示筛查/组合/历史标记、已见与待补
证据；无触发时也区分明确未触发与未评估。趋势和报告输入包含这些差异，
不再默认写“19 项均未触发”。

## 6. 派生版本

- `ALERT_RULESET_VERSION = 2026-10-26.b06.1`
- `SCORING_RULESET_VERSION = 2026-10-26.b06.1`（共享文本语义变化，非分值变化）
- `DERIVED_GENERATOR_VERSION = 2026-10-26.b06.1`

旧报告继续按 B04 的输入指纹和版本规则判断失效，用户显式重新生成；不自动请求
模型，不回填未采集的脉诊、视频或触诊事实。
