# 从中医著作到知识库

这篇指南帮助你选择适合整理成知识库的著作资料，并说明怎样把资料交给 AI 生成综合知识库。目录、文件格式和校验规则由 [自建知识库格式与导入规范](KB_AUTHORING.md) 统一说明，这里不再展开。

**个人自建知识库时，只需用 AI 制作一个综合知识库 ZIP，不必再拆成体质、食疗、方剂三个子库或三个 ZIP。** 三类专用包用于确有按类独立提供、更新和重置资料需求的场景，不是个人建库的额外步骤。综合包内的标准目录只用于主题归类，不是三个子库。

## 1. 先看看自己需要哪些内容

知识库的作用是为检索和报告候选提供资料，不会训练模型，也不会自动改变系统的评分、权重、红线或剂量规则。选书之前，可以先检查下面五类内容。它们只是核对方向，不要求一本书全部具备。

| 内容方向 | 可以从资料中寻找什么 |
| --- | --- |
| 体质与辨证框架 | 体质、证候、病机如何分类、关联和判断，而不是只有体质名称或孤立方名 |
| 舌诊及其他望诊 | 舌质、舌苔、舌下络脉，以及资料实际涉及的头面、目、耳、手、皮肤等观察内容 |
| 九种体质分类 | 九种体质的分类名称、判定维度和依据，能够回查明确的标准或资料来源 |
| 方剂、方证与煎服 | 方剂的适用条件、方证、方义、煎服方法和禁忌；出处不清的剂量不要收录 |
| 食疗宜忌 | 饮食适宜与禁忌、四气五味，以及相应的适用条件和限制 |

体质分类依据不能代替完整的辨证框架，舌诊资料也不能自然推出方剂或食疗内容。缺少某一类并不影响建库，可以先整理手上确实有的资料，以后需要时再补充。没有依据的部分不要让 AI 编写。

## 2. 开发样本怎样搭配资料

开发本系统时，样本知识库使用过《中医诊断学》、中华中医药学会《中医体质分类与判定》（ZYYXH/T 157-2009），以及方剂、经方类著作。几类资料的分工如下：

| 资料 | 适合整理的内容 | 使用边界 |
| --- | --- | --- |
| 《中医诊断学》 | 舌质、舌苔、舌下络脉等舌诊内容，以及资料实际涉及的望诊词汇和部分现代望诊基线 | 不把它当作九种体质分类、方剂或食疗资料的来源 |
| 《中医体质分类与判定》（ZYYXH/T 157-2009） | 九种体质的分类名称、判定维度和依据 | 不提供完整的舌诊词表，也不替代其他辨证资料 |
| 方剂、经方类著作 | 方证、治法、方义、煎服和禁忌；确有出处时也可以整理相关饮食宜忌 | 以实际读到的章节为准，未读到的内容不补写，出处不清的剂量不收录 |

这个例子说明了一种搭配方法：诊断类资料提供望诊和辨证内容，体质标准提供分类依据，方剂、经方资料补足方证和煎服。你可以根据自己的需要调整组合，不必照搬样本，也不必有了一整套书才开始。

版本需要单独核对。样本中使用的是 2009 年中华中医药学会发布的团体标准，不是行业标准。现行推荐性国家标准为 GB/T 46939-2025《中医体质分类与判定》，自 2026 年 4 月 1 日实施。整理新资料时应记录实际版本，不要把新旧版本的判定条目、计分和方法混写。

## 3. 怎样判断一本书适不适合

先翻目录和准备使用的章节，不必急着把整本书交给 AI。合适与否，主要看以下几点：

1. **内容是否对应需要。** 书里确实有你准备整理的主题，并能保留适用条件、限制和上下文。
2. **文字是否能够核对。** 优先使用可搜索、可复制的电子版。扫描件应先做 OCR，并抽查识别结果；无法辨认的页面不能猜字。
3. **出处是否清楚。** 书名、作者、版本、章节和页码应当可以回查。PDF 页码与书页页码不同时，整理时最好同时保留。
4. **使用是否获得许可。** 能阅读不等于可以复制或再分发。把资料发给云端 AI 前，还要确认许可和隐私要求。

如果一本书只覆盖部分内容，就只使用这些部分。为了凑齐类别而从其他书籍、模型记忆或网络资料补写，会让来源变得难以核对。

## 4. 把资料和格式规范交给 AI

你不需要自己研究知识库的目录和字段。把**著作资料的电子版**和项目中的 **`docs/KB_AUTHORING.md`** 一起交给能够读取这些文件的 AI，请它按规范生成一个综合知识库 ZIP 即可。还没有这份文件时，先[下载 KB_AUTHORING.md](KB_AUTHORING.md)。

可以直接这样交代：

```text
请先阅读我提供的 KB_AUTHORING.md，再阅读这些著作电子版。
按规范生成一个可导入本系统的综合知识库 ZIP，只使用我提供的资料。
请同时列明实际读取范围、无法辨认或未处理的内容，不要猜测或补齐。
```

如果资料不止一本，仍然只生成一个综合 ZIP，不要拆成三个子库。AI 声称已经生成时，应确认自己确实取得了 ZIP 文件，而不是只有一段代码、文件清单或正文示例。

详细的目录结构、文件数量与大小限制、清单和别名词典写法，都以 [自建知识库格式与导入规范](KB_AUTHORING.md) 为准。

## 5. 导入前自己要做的复核

AI 生成文件不等于内容已经核对。导入前至少检查：

- 正文能否查回所标的书名、版本、章节和页码；
- 原文节选、摘要和 AI 自行说明是否区分清楚；
- 适用条件、禁忌和上下文有没有在改写时丢失；
- 无法辨认、未读取或出处不明的内容是否仍然明确保留在核对记录中。

格式校验只能判断 ZIP 是否符合导入要求，不能证明医学内容准确。报告中的候选参考也需要回查原资料，不能作为诊断依据。

## 6. 导入综合知识库并检查结果

1. 打开「设置 → 知识库」，展开「综合知识库」。
2. 确认综合知识库开关已开启，选择 AI 生成的 ZIP，点击「导入综合知识库」。非本机访问需要先验证管理口令。
3. 等待校验完成，确认状态为「知识库可用」，并核对可检索 Markdown 数量。
4. 从资料中选几个确定存在的词检查检索；如果使用报告候选，再回到原书核对出处和含义。

每次成功导入都会**替换综合导入副本，而不是与旧 ZIP 合并**。新 ZIP 必须包含希望继续使用的全部综合资料，原电子书、工作文件和旧 ZIP 请自行备份。导入本身不调用模型。

普通自建不需要开启「严格分类模式」，也不需要配置三个子知识库。只有以后确实需要按类独立提供、更新或重置资料时，才使用「子知识库」分组中的专用导入。

## 7. 常见问题

| 情况 | 怎么处理 |
| --- | --- |
| 一本书不能覆盖所有内容 | 只整理实际覆盖的部分，不为凑齐类别补写。 |
| 同时使用多本著作 | 仍生成一个综合 ZIP，不必按主题或书籍拆成子库。 |
| 只有扫描版 | 先做 OCR 并核对；不能辨认的页面不要猜字。 |
| AI 给不出实际章节和页码 | 先不要导入，要求它说明真实读取范围并重新整理。 |
| 再次导入后旧资料消失 | 综合导入采用替换语义，从自行保存的完整工作文件或旧 ZIP 恢复。 |

需要检查 AI 是否按系统要求组织文件时，直接查阅 [自建知识库格式与导入规范](KB_AUTHORING.md)。
