# 医学治理与未标定辅助模式（B08）

**日期**：2026-10-27
**状态**：工程与产品边界已定；未进行独立医学标定。本文件不是医学有效性证明，也不授予任何处方或剂量权限。

## 1. 主人决定与当前边界

2026-10-27，主人明确：无法取得真实医学标定数据，照片体征判读交由用户自配置的视觉大模型，系统通过 welcome 页和使用手册披露风险。因此，不再把取得医学标定数据集或医学人员签认作为当前辅助模式的使用、交付前置。

welcome 页已说明本系统不是医疗器械、输出不构成医疗诊断，识图准确度取决于所选视觉模型，并要求对照原图人工复核；使用手册同样要求方剂建议经执业中医师审核。视觉模型负责照片体征判读，本地规则负责评分，辨证文本由所配置的辨证模型或本地速览生成，三者不能混称为已经验证的医学判断。

这一决定不等于模型准确率已获证明，也不把免责声明当作标定证据。当前按**未标定的模型辅助模式**交付，不改变现有分值、舌色档数、危重规则、临床总分、置信度或剂量行为，不生成虚构的医学性能指标。本批没有读取真实 `.env`、健康记录或照片，也没有调用真实模型。

## 2. 逐项裁决

`src/governance.py` 从评分规则和预警出处生成清单，覆盖现有全部评分项及以下治理议题：

- 舌下暗红/2.7mm 与现有淡紫/<2mm 的不同口径；
- 舌质五档的信息损失与可接受替代；
- 绝汗亡阴/亡阳分类、急性黄疸拦截级别、`tongue_critical` 的存废与边界；
- 临床总分的去留与历史重算策略；
- 覆盖四维即可给具体剂量的权限。

每项包含：

| 字段 | 含义 |
|---|---|
| `id` / `dimension` / `indicator` | 稳定标识及所属维度、指标 |
| `current_value` | 当前实现值；用于发现清单与代码漂移，不等于推荐值 |
| `evidence_refs` | 原著/教材出处及文件哈希，或明确标注的经验依据 |
| `proposed_value` / `reason` | 拟议值及裁决理由；未裁决时拟议值为 `null`；评分迁移取 0–10 数值，类别议题迁移取非空字符串 |
| `approved_by` | 主人或医学人员的可追溯签认；AI 名称不能作为签认 |
| `migration` | `keep_current` / `migrate` / `retire`，明确保留、迁移或退出 |
| `status` | `pending` 或 `approved`；pending 不会被当成签认 |
| `calibration` | 与该决策对应的真实标定报告；pending 时为 `null` |

pending 表示当前值未经独立医学验证，**不阻塞既定辅助模式的使用**，也不是等待模型自我批准。`approved` 则保留给具备非 AI 签认、真实标定报告和明确迁移方式的严格审批路径；没有这些材料时不把项目标为 approved。校验器只检查材料结构与内部一致性，不能核实签名身份、参考结论是否真实或模型是否确有医学有效性。

医学规则的实际变更须由主人明确决定并写明迁移，另行实施和验证；视觉模型的判读输出不能代替代码变更授权。若未来具备独立标定材料，再用 `validate_decision_table()` 校验；校验通过也不会自动改规则。

更新或检查清单：

```bash
python3 scripts/governance_inventory.py
python3 scripts/governance_inventory.py --check
```

默认命令根据当前代码重建 pending 清单，不会把 pending 提升为 approved。已有人工裁决内容须先在独立、受控的决策记录中保存，不要用重建命令覆盖。当前生成文件没有真实标定结果。

## 3. 模型核对与可选标定

当前模式下，部署者按照 README 的换模型 checklist，使用自己有权使用的照片检查输出结构、规范词落域与重复识图稳定性，并对照原图人工复核。同图多次一致只说明输出稳定，**不证明判读正确**；模型不能给自己的结果充当独立参考真值，也不能据此编造误报率、漏报率或医学有效性结论。

若未来能够取得合法授权、脱敏且有独立参考结论的数据，可选择执行严格标定，但它不是当前辅助模式的交付前置。标定集须覆盖正常、明确异常、边界以及染色、光线、拍姿差异；由人工或医学专业人员独立记录参考结论，无法可靠判读者标为未知。保留逐图、逐字段结果及失败样例，报告不得放入照片、身份信息或 API Key。

严格标定应让同一图片至少重复识图两次，保存模型名、端点配置和实际参数，并报告戴阳、黄染、齿痕、腻腐、舌下和危重提示的字段级一致率、误报/漏报/未知率、规范词落域及评价总数。`validate_calibration_report()` 对这些材料做结构约束；`authorization` 字段不是授权本身，`deidentified` 字段也不能替代实际脱敏，mock/fake/dummy 模型和模拟数据集不能冒充真实标定证据。

没有独立证据时，现有规则保留为未验证经验规则，不把新词或新权重宣称为已验证医学规则。无法稳定判读的字段继续作为人工参考或退出自动评分，不能用降低未知标准来追求“跑通”。

## 4. 趋势口径与历史记录

详情页和趋势页明确标注：观察汇总与偏离值均为**未经验证的界面指标**，不作为疾病严重度或处方依据；总分及历史重算结果未获独立医学验证。这是风险提示，不改变当前数值，也不要求部署者先取得医学标定数据才能查看。

现有趋势会读取历史观察并按**当前规则**重算，同时显示来源规则版本与当前计算版本。没有保存旧规则快照时，不能伪造“旧规则数值”或声称完成了同口径历史对照。后续若主人决定废弃总分或修改权重，须单独确定历史重算、保留原值或停止展示的策略，并写入迁移说明。
