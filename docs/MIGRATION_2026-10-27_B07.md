# B07 采集能力与复合记录 v2 迁移说明（2026-10-27）

> 范围：形状 B v2、观察/声明模型、采集能力约束、复合舌苔、最小上下文与派生失效。
> 不决定新的医学分值或出方权限，不要求一次收齐病历，不延误危险提示；B08 的
> 医学权重与真实标定不在本批范围。

## 1. 形状 B v2 与旧记录

新写入以形状 B 为主，新增：

- `schema_version = 2`；
- `observation_meta`：按 B 路径保存每个指标的采集事实；
- `declarations`：独立的用户声明，不写进观察；
- `derived_meta`：输入指纹、评分/生成器版本与更新时间。

A/B/C 旧记录仍由原 `DailyRecord` 路径读取。合并旧 B 时可以保留缺失的元数据，
**不伪造历史采集来源或确定性**。没有批量迁移或改写用户原始 JSON。

`Observation` 保存 `indicator_id/source/method/raw/certainty/evidence/value`。
`raw` 是原始输入，`value` 是规范化后的值，两者可能不同；`certainty` 为
`unverified / user_confirmed / self_reported / unknown`，不是经过临床校准的准确率。
`Observation.normalized` 在 `unknown` 时为空，不允许无依据值进入评分。

`Declaration` 有四类：`declared_normal / skipped / refused / unavailable`，带
`dimension/part/reason`。声明不是观察，也不等于排除异常。旧 `skipped_dimensions`
和声明占位仍可读；新记录不再把“未拍摄（用户声明正常）”写成观察值。

## 2. 采集能力约束

约束在 `src/observations.py` 和注册表共同执行，覆盖上传、手动录入、草稿修正、
记录修正、旧草稿组装及 `input_validator` 的持久化校验：

| 指标/事实 | 允许与拒绝 |
|---|---|
| 舌体动态、鼻翼煽动、舌强语謇 | 视频/人工动态/问诊；静态照片拒绝，旧 `critical_signs` 同样检查 |
| 舌下绝对毫米或毫米阈值 | 需要可靠比例尺；无比例尺返回 unknown，不写绝对测量值。相对粗细仍可按原枚举 |
| 下睑颜色 | 必须明确暴露下睑结膜；未暴露返回 unknown，不计覆盖，不填正常或异常颜色 |
| 皮肤凹陷 | 人工触诊/自陈/问诊；普通皮肤照或默认手动输入不得直接判定。可见全身浮肿仍可按既有采集 |
| 黄汗 | 问诊/自陈或衣物证据；普通皮肤照拒绝。衣物证据须显式选择 `kind=clothing` |
| 掌温 | 触诊/问诊/人工来源；照片不能判温 |

无比例尺和未暴露是**可诊断的 unknown**：原始尝试、方式和原因保留在
`observation_meta`，`value` 为空。`DailyRecord.get_observation()` 读取时以
`UNKNOWN_OBSERVATION_MARK = 无法判读` 表示，便于显示和 `assess*` 返回 unknown；
该标识不写入原始观察，也不计真实覆盖。无权的采集方式则返回 400/校验错误。

向导可选项包括人工/肉眼、触诊、问诊/自陈、有比例尺测量、视频/动态观察、
下睑已暴露及衣物证据。测量值必须带单位（例如 `3mm`），也可用原相对粗细枚举。

## 3. 复合舌苔与第 45 项指标

新增 `coating_amount`（苔量），与 `coating_distribution` 分开；分布不再兼任苔量。
复合描述拆为：`color / thickness / moisture / greasy / peeling / amount / distribution`。

- 未观察到的轴不补值，原始复合描述保留在每个相关字段的 `raw` 中。
- `厚腻` 等既有评分别名保留在对应字段，避免借拆分之名新增医学权重；
  颜色、厚薄、润燥等仍使用既有规则。
- 局部无苔不直接当作镜面舌；镜面仍优先使用结构化剥落或明确的危重舌象。
- 无法识别的复合文本保留在 `coating.raw`/原始记录，不能冒充已分轴事实。

`coating_amount` 是参考项，不单独评分；新词及出处已同步到注册表与
`docs/VOCAB_PROVENANCE_2026-10-16.md`。

## 4. 最小上下文与派生失效

`context` 可选包含：

- `age_band`：未成年/成年/老年/不便提供；
- `chief_complaint`、`duration`；
- `recent_dyes`；
- `medications`、`sweating_medication`；
- `history_allergies`、`sleep`、`congenital_signs`。

这些是有限背景，不是完整病历，不能替代观察、触诊或脉诊。文本每字段最多 300 字，
不收姓名、证件号、精确出生日期、住址或联系方式；不为空才不保存，不要求收齐。

`observation_input_hash()` 现在包含规范观察、`observation_meta`、`declarations`、
`schema_version`、`inquiry` 和 `context`。`DERIVED_GENERATOR_VERSION =
2026-10-27.b07.1`；评分规则版本仍为 B06.1（没有医学分值变更），预警规则版本
保持 B06.1。采集证据、声明或上下文改变时，按 B04 的版本与输入指纹规则重算，
不自动调用模型重写报告。

## 5. 读取、修正与校验

- `DailyRecord.get_declarations()` 读取 v2 声明，也兼容旧 `skipped_dimensions`。
- 新写入、修正和合并共享 `capture_observation()`；只有规范化值进入 `observations`，
  原始输入与采集事实进入 `observation_meta`。
- `input_validator` 检查 schema 版本、元数据来源/方式/raw/certainty/evidence/value、
  实际观察一致性及声明类型。即使绕过页面直接写 JSON，也不能把无权事实变成有效记录。
- 前端使用服务器返回的规范化 `value` 更新草稿，避免把 unknown 重新写回观察；
  跳过时同时清理旧观察和元数据。
- 模板保留形状 A 的可选 `state=unknown`；形状 B v2 的三态预警与评估元数据继续沿用。
