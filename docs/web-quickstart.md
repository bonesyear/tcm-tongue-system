# Web 界面快速上手

> 面向自托管使用者的 Web 操作指引（对应 v1.7.5+）。
> 拍摄纪律（光线、角度、各部位怎么拍）不在本篇重复，见 [user-guide.md](user-guide.md) 第三、五章。

---

## 一、安装与启动

核心库零依赖（纯标准库）；Web 层独立依赖为 Flask、Waitress、Pillow（照片清洗）和 tzdata（跨平台 IANA 时区数据）：

```bash
pip install -r web/requirements.txt
```

启动：

```bash
python web/app.py
```

浏览器打开 **http://127.0.0.1:8600**。常用参数：

| 参数 | 作用 |
| --- | --- |
| `--port 8601` | 换端口 |
| `--lan` | 绑 0.0.0.0 开放局域网（须先设口令，见第七章） |

停止服务：在运行终端按 `Ctrl+C`。

Web 入口使用 **Waitress 3.0.2**：8 个工作线程、连接上限 64、通道超时 300 秒、backlog 32，请求体上限与现有图片上传限制一致。通道超时只处理连接不活跃，不替代模型调用的总时限；非回环监听仍必须先配置管理口令。请通过 `pip install -r web/requirements.txt` 安装 Web 专用依赖，不再以 Werkzeug 开发服务器作为部署入口。

**进程边界**：推荐每个数据目录只运行一个服务进程。配置和记录写入有线程/进程锁，但 welcome 确认与管理会话只存在于各自进程内存中，多进程需分别确认和登录；这不等于已经支持负载均衡、多机或共享网络盘部署。多窗口/多设备同时编辑以文件版本冲突提示为准，不要绕过冲突提示强行覆盖。

## 二、首次进入

1. 打开任意页面（包括设置页）会先看到**使用前须知**（开源许可 / 免责声明（含自建知识库的资料许可、准确性与人工复核责任）/ 模型精确度说明），三项勾选后点「全部已了解，进入系统」。每次服务重启后需重新确认一次，这是设计而非故障。
2. 未配置且未关闭视觉模型时，系统引导到**设置页**；已主动关闭则直接进入手动录入模式。
3. 库里一条记录都没有时，首页提供「**载入示例数据**」按钮——载入一条合成示例记录（页面各处已标注「合成数据」），用来先把五个页面都点一遍熟悉界面。要清掉它，可在详情页使用「删除当日数据」。

部署时若系统时区不是当地时区，请配置 `TCM_TIMEZONE`（如 `Asia/Shanghai`）；向导会提示服务器与本机日期不一致，跨午夜可继续原日期的草稿。

## 三、配置模型（设置页）

两组模型都**可选**，配置只写回本机项目根的 `.env` 文件，不入库、不上报。卡片右上角的启用开关只保存该开关，不会顺带保存其他未提交输入；关闭视觉模型可手动录入，关闭辨证模型使用本地规则速览：

| 分组 | 用途 | 对应环境变量 |
| --- | --- | --- |
| 视觉模型 | 七部位照片识图 | `VISION_API_KEY` / `VISION_BASE_URL` / `VISION_MODEL` / `VISION_TEMPERATURE` / `VISION_TIMEOUT` / `VISION_MAX_TOKENS` |
| 辨证模型 | 六经辨证、生成报告 | `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` / `LLM_MAX_TOKENS` / `LLM_TIMEOUT` |

每组的操作顺序：**填 API Key → 填端点 → 点「获取列表」拉取可选模型 → 点「测试连通性」确认 → 保存**。

注意事项：

- 端点必须是 **OpenAI 兼容**接口。缺 `/chat/completions` 后缀时 Web 层会自动补齐并在服务日志告警，但建议一次填全（形如 `https://…/v1/chat/completions`）；Anthropic 协议端点不支持。
- API Key 保存后页面**不回显真值**，只显示「已保存（输入新值即覆盖）」；要删除就勾「清除」再保存。
- 「温度」推荐**留空**（由模型默认值生效）；部分端点有服务端下限（如 DashScope 钳到 0.6），设 0 不等于确定性输出。
- 「超时」推荐 150–300 秒：识图是大请求，太短会中途失败。`VISION_MAX_TOKENS` 默认 600；`LLM_MAX_TOKENS` 默认 16000；`LLM_TIMEOUT` 默认 150 秒，均为正整数。
- 端点必须是 HTTP(S)；`VISION_BASE_URL` 必填，未配置不会发往默认第三方。本地/Ollama 端点可用；重定向仅允许同源，响应大小和总时长有限制。
- 只复用已保存 key 拉取模型列表时，端点必须与已保存端点同源；换源须同时输入新 key。清除视觉 key 后不会从其他项目或 profile 取 key。
- **更换视觉模型后必须重新核对识图措辞**：新识图/修正入口只接受封闭词表中的值，词表外文本保留原值并要求人工复核，不会成为已确认观察；历史兼容 `score*` 的 0 也不等于确认正常。

### 知识库 ZIP（可选）

公开仓不提供原知识库文件或在线下载。「设置 → 知识库」前方的「子知识库」分组默认折叠，点击标题可展开中医体质辨证、食疗、方剂三类专用导入，分别对应 `TCM_KB_CONSTITUTION_ROOT`、`TCM_KB_DIET_ROOT`、`TCM_KB_FORMULA_ROOT`。分类 ZIP 必须含与卡片匹配的 `kb.yaml`；每类可单独更新和「重置」，重置只删除本类导入副本并设置 `TCM_KB_<类别>_DISABLED=1`。外部原库和其他类别不受影响，完整目录收在“技术详情”中。

子知识库整组、三个子库和综合库共有五个独立开关，切换即保存：

- 关闭整组会暂停三个子库及综合回退，但保留各子库自身选择；恢复整组后按这些选择生效。
- 子库开关只改变本类自身选择；关闭综合库只暂停综合根及分类回退，不影响已配置的独立专用根。
- 开关不删除知识库文件，只控制对应内容能否进入检索候选、模型报告和本地速览。
- 「严格分类模式」仍在子知识库分组内，独立于整组开关；开启后只使用各类专用根，不回退综合库。

综合知识库位于子知识库分组之后。手中只有一本中医著作时，打开知识库卡片右上角的[从中医著作到知识库](kb-guide.md)，按指南完成资料整理、原文复核、综合 ZIP 打包、导入和检索验收；目录结构、清单和替换语义均在指南中说明，无需配置模型即可完成导入。

新 clone 默认不读取外部旧目录。分类导入只替换本类副本并解除本类自身停用；综合导入替换综合副本、保留三类专用副本并解除综合自身停用。导入不会自动开启整组，也不改变其他类别的选择。不要把唯一原稿放在导入副本目录。非法包、文本/词典错误或激活失败会保留旧副本；配置写回失败会按事务前字节恢复配置和目录，环境变量锁定时当前配置不切换。

自定义资料只影响检索与候选参考，不训练模型，也不自动改变医学权重、红线、评分或剂量规则。默认报告按当前可用类别构造统一检索视图：三类齐全与综合库一致，双模块与源库对应子集一致，缺类不把该类证据送入模型。三类齐全时，未按专类目录组织的综合资料作为通用候选单独处理；缺类时无法确定归属的共享资料会明确报错，专用根自定义目录不受影响。每类独立区分未配置、空库、可用和错误；缺体质库隐藏体质/辨证内容，缺食疗库隐藏饮食建议，缺方剂库隐藏方药及完整方药报告，旧记录已有内容也不能绕过。报告保存各类别状态与版本，换库或启停导致有效来源变化后旧报告提示过期；恢复原状态且指纹一致时可继续显示。缺方剂的方名/剂量、缺食疗的结构化饮食、缺体质的结构化辨证输出会在写入前拒绝。报告尾部的条文是候选参考，不保证模型实际采用；本地速览使用项目内置规则计算，但只有对应类别可用时才展示。

## 四、每天的流程：拍照向导

顶栏「拍照」进入，一步一个部位（舌面 → 舌底 → 头面 → 目 → 耳 → 手 → 皮肤）：

1. 每步右侧有该部位的**拍摄纪律**（如舌底禁用闪光灯），先读再拍。
2. 点虚线框拍照或上传照片；图片先校验大小/像素、按 EXIF 方向重排并剥离元数据，再暂存到 `records/photos/<日期>/.staging/`。识图结果填入草稿，提交成功后才替换正式原图；旧图及旧扩展名自动备份。
3. 没法拍或不想拍时，可「跳过（声明正常）」「跳过（未覆盖）」「拒绝拍摄」或
   「无法拍摄」。这些都写入独立 `declarations`，**不是观察，也不计真实覆盖**；
   旧记录中的声明占位仍兼容读取。可选「最小上下文」只补充有限背景，不收身份信息。
   采集方式与证据条件可手动选择：比例尺、下睑暴露、触诊/自陈、黄汗衣物证据；
   无比例尺不报毫米，未暴露不填下睑颜色，凹陷不凭照片推断。
4. 七步走完点「**提交分析**」：自动评分、生成记录。若观察值命中危险信号（如镜面舌、面红如妆），会先弹**拦截式提示**要求肉眼复核裁决，不静默通过。弹层默认保留每项警示，可逐项改为误报；确认绑定当次证据，证据变化后须重新复核。误报只记录人工判断，不等于“未触发”。
   merge 中已保留且证据未变的旧红线不重复弹层，也不能把未触及的旧项判为误报。「返回修改观察/问诊」只关闭弹层，不会清除记录。
5. 当天已有记录再进向导，会给三个选择：**补充未覆盖维度 / 重新分析（旧版自动备份）/ 取消**。

识图失败的常见原因：视觉模型未配置（清洗图只保留在暂存区，不会覆盖已提交原图）、超时设太短、端点或模型名填错。上传超过 20 MiB、超过 4000 万像素或文件不是有效图片时会被拒绝。

## 五、记录详情与修正

「记录」页（首页）是月历 + 统计条，点任意一天进详情页：

- 头部：总分、覆盖度、置信度、模板版本；六维卡片列出全部观察值与单项分（点刺、掌温等「参考项」以虚线徽章区分，不计分）。
- **原图对照**区：当天拍过的照片原图，供肉眼复核——点刺、腻腐两个字段以肉眼为最终权威。
- 发现识图有误，点「**修正**」：改观察值 → 自动重评分 → 覆盖保存。值须为封闭词表内不超过 64 字的单行文本，不能用“未拍摄”声明或“无法判读”占位代替实测。
- 需要删除某一项时点编辑区的「**清除此项**」，不能用空字符串代替。保存和清除都会备份旧版、记录修正审计并重新评分；旧版本在 `records/_backup/`，记录带 `manually_corrected: true` 标记。
- 红线证据被修正或改答消失时，系统记录 `clear` 审计；无关修改不会使误报复活。裁决变化会使旧报告过期，详情页明确区分误报与未触发。
- 识图遇到未知字段、异常类型或词表外文本时，原值会保留供复核；这些异常不会变成已确认观察。点刺依据、耳道分泌物等注记单独保存，不参与预警词扫描。
- 保存和生成报告都有代码闸门：LOW 不允许新增具体方剂，MEDIUM 不允许新增具体剂量。原记录已有的同类校验问题会作为存量警告显示，不妨碍修正其他字段；本次新引入的违规不会写入文件。
- 多窗口或手机、电脑同时编辑时，若检测到其他请求已经更新文件，系统会拒绝旧版本写入并提示刷新；请查看最新内容后重试，不会静默覆盖刚保存的记录或草稿。
- 「**恢复/撤销**」回到当前代修正前状态，再次执行可撤销最近一次恢复；报告保留，当前状态先自动备份。
- 「**删除当日数据**」需展开确认并再次提交，永久删除当日记录、照片、暂存、草稿和全部备份，不能恢复。普通备份按每日 20 份保留，pristine 和当前撤销所需快照优先保留。
- **辨证报告**卡在详情页底部：三观（表里/正邪/津液）、四证、六经归属、核心病机、方剂（含剂量免责提示）。换过模型或对结果不满意可点「重新生成」。

## 六、趋势页

按周查看：六维偏离度散点、舌象雷达（周首日 vs 周末日对照）、舌象九轴逐日热力图、本周摘要与趋势解读。

- 顶部「上一周 / 下一周」翻页；当周无记录时会给出「**最近一次记录在第 N 周，去看看 →**」的直达链接；最新文件若损坏，会回退到最近可读取的记录。
- 周报 `week_id` 使用实际滚动七天窗口的起止日期（`YYYY-MM-DD_YYYY-MM-DD`），不再使用 ISO 周号；正常 0 分与无观测分别处理。
- 首页只计算最近 7 条摘要，月历复用摘要缓存；同日多份非规范记录按 mtime 选档并告警，中文副本、备份、快照和 `(1)` 等副本不参与选档。
- 体质方向判定需要 2–4 周连续记录，单日高分不必过度解读。

## 七、手机拍照（局域网）

手机和电脑连同一 WiFi 时：

1. 先在设置页「访问与安全」设置**管理口令**（`WEB_ADMIN_TOKEN`）并保存；
   口令与监听地址可以同次保存。无口令的非回环监听会拒绝保存或启动。
2. 重启服务时加 `--lan`：`python web/app.py --lan`；
3. 手机浏览器打开设置页里显示的「本机局域网地址」（形如 `http://192.168.x.x:8600`，
   端口以实际启动参数为准）。请使用页面显示的地址或 `localhost`，不要自行改用其他域名。
4. 先完成使用前须知确认，再在设置页「管理口令验证」输入口令并提交。
   验证建立本次服务进程内的会话；服务重启后须重新确认并验证。

安全边界：未确认须知的局域网设备不能查看设置页；确认后、未验证口令时只能看到
**只读设置页**，不能读取记录、趋势或照片，也不能写入或调用模型。
口令只通过 `/settings/login` 的 POST 表单提交，旧的
`?token=口令` 不再作为凭据；保存后的跳转不携带口令。会话使用 HttpOnly、
SameSite=Strict cookie，HTTPS 请求另加 Secure。直接启动使用 HTTP，不提供传输加密，
请只在可信局域网使用，不要直接暴露到公网。welcome 的确认不是身份验证。

## 八、数据都在哪

| 内容 | 位置 |
| --- | --- |
| 每日记录（JSON） | `records/daily/` |
| 照片 | `records/photos/<日期>/` |
| 修正前的旧版备份 | `records/_backup/` |
| 模型配置与口令 | 项目根 `.env` |
| 私有知识库 | `<TCM_DATA_ROOT>/private_kb/<类别>/`（设置页导入） |

以上全部**只存本机**，且都在 `.gitignore` 里，不会随 git 上传；请自行定期备份 `records/`。
`records/_backup/` 用于本机恢复，不等于离线或异地备份；真实数据的外部备份请另行加密并做恢复演练。
公开仓不再附带原知识库；如需完整检索和报告引用，请在设置页导入你有权使用的综合 ZIP（或有进阶需求的分类专用 ZIP），
由程序管理副本自动启用。外部旧目录默认不读取。公开测试只用合成资料，不需要私有内容。

## 九、常见问题速查

| 现象 | 原因与处理 |
| --- | --- |
| 打开就跳须知页 | 服务重启后的正常设计，三勾选确认一次即可 |
| 提交时弹危险信号拦截 | 命中保守词表，按提示肉眼复核后裁决，不是报错 |
| 某项读作 0 分但看着正常 | 识图措辞落出封闭词表（KNOWN_ISSUES §2），用修正功能改词，或标定 prompt |
| 识图中途失败 | 超时太短（设 180–300），或端点/模型名有误，用设置页「测试连通性」排查 |
| 换电脑 | 重新 clone → 装依赖 → 配 `.env` → 把旧机 `records/` 整个拷过来即可 |
