# B12 配置、出站请求与识图客户端（v1.13.5）

**日期**：2026-10-27
**范围**：F22、F24、F46、F50、F51、F52、F54、G9、G10、G12、F25、F26。仅修改配置、Web/CLI 调用与测试，不改变医学权重、预警规则、剂量策略或记录结构。

## 必须知道的迁移变化

1. **`VISION_BASE_URL` 现在必填**。未配置端点会明确报错，不再把 key 或照片发往默认第三方。默认模型名 `qwen3.8-max` 仍只是示例，请替换为自己的模型；本地/Ollama 的 HTTP 端点继续支持。
2. **CLI 与 Web 都按“非空环境变量 > `.env`”读取配置**。`VISION_MODEL`、`VISION_BASE_URL`、`VISION_API_KEY`、`VISION_TEMPERATURE`、`VISION_TIMEOUT`、`VISION_MAX_TOKENS` 均在调用时解析，不再依赖 import 时的 `MODEL` / `URL` 常量。
3. **私有历史路径默认不再读取**。CLI 仅默认读取当前目录 `.env` 与 `~/.config/tcm-tongue/.env`；确需旧的 `~/.hermes/...` 路径时，显式设置 `VISION_ENABLE_LEGACY_ENV_PATHS=1`。`DASHSCOPE_API_KEY` 仍兼容并告警，但 Web 不从该变量或其他 profile 偷取 key。
4. **`vision_client.call` 改为关键字配置**。完整形式为 `call(img, prompt, *, model, url, key, timeout=None, max_tokens=None, temperature=None)`。缺省参数可从当前配置解析；Web 始终显式传入同一份快照，兼容调用方应更新测试桩以接受这些关键字。
5. **清除 key 就是停止调用**。Web 连通性测试发现 `VISION_API_KEY` 为空时直接返回未配置，不发起 HTTP，也不读取其他项目配置。

## 配置快照与设置页

- `web/app.py` 的 `cfg()` 在每个请求内只读取一次 `.env`，所有模型、端点和 key 都来自该快照；不再通过 `os.environ` 或 `importlib.reload` 传递配置。新请求才读取新值。
- 新增 `VISION_MAX_TOKENS`（默认 600）、`LLM_MAX_TOKENS`（默认 16000）和 `LLM_TIMEOUT`（默认 150 秒）输入项。超时和额度必须是正整数，温度为有限数值；非法值返回 400，报告配置错误返回可诊断 JSON，不再冒未捕获 `ValueError`。
- `LLM_MAX_TOKENS` 与 `LLM_TIMEOUT` 从同一快照进入报告调用；不再只认进程环境。旧的三元组 `llm_cfg` 仍可兼容，默认额度与代码统一为 16000。
- 环境变量非空时才锁定。空串环境变量按 `.env` 回退处理，不再出现“UI 可改但服务端静默忽略”。被锁定字段即使手工提交也会跳过，并在 `locked` 参数与设置页中明确列出。
- 保存端点时拒绝非 HTTP(S)、内嵌凭据及链路本地/云元数据 IP 字面量。合法的本地和私网 HTTP 服务不一刀切禁用。

## `.env` 读写与错误恢复

- 统一注释、引号和转义：`#` 前是空白且值未被引号包住时才是行内注释；含 `#`、引号、反斜杠或空白的值写入时用双引号及转义保存，写后回读核对。
- 支持起始 UTF-8 BOM；保存时规范为无 BOM。保留既有行和注释，更新的键保留原位置。
- 键名只允许 `^[A-Z_][A-Z0-9_]*$`。值拒绝 NUL、CR/LF 以及 `splitlines()` 识别的其他换行字符，包括 U+2028/U+2029，阻断一阶和二阶配置注入。
- 写入沿用原子替换，并兼容顶级模块与 `web` 包两种导入方式。非 UTF-8 或引号不完整的配置产生 `EnvDecodeError`；GET 显示含路径、字节位置和转码建议的可恢复文本，POST 引导到 `env_error`，不再全站 500。用户须先修复该文件再使用模型功能。
- CLI 保留非 UTF-8 告警与替换字符兼容路径，但与 Web 共用注释、引号和 BOM 解析。

## 出站安全边界

`web/safe_fetch.py` 是视觉和辨证客户端共用的标准库传输层：

- 仅允许 HTTP(S)，默认响应上限 **8 MiB**，以分块读取和单调时钟限制总时长，超时覆盖连接、重定向、重试和响应读取。
- 关闭自动重定向，逐一检查 Location。只允许同源跳转；跨主机、端口/协议变化和 HTTPS 降级在发出下一跳前拒绝，不把 Authorization 带往新源。
- 429、502、503、504 最多重试两次，退避 0.5 秒、1 秒；其他状态不盲目重试。401/403、404、429 与其他参数错误分别给出提示。
- 拉取模型列表时，如果只复用已保存 key，覆盖端点必须与保存端点同源（含默认端口归一）；换源必须同时显式输入新 key。环境变量锁定的 BASE_URL 忽略覆盖。
- 链路本地/云元数据 IP 字面量被拒绝，其他本地/私网地址保留合法用途。本批未增加 DNS 重新绑定防护或公网 allowlist，不把它描述成完整 SSRF 解决方案。

## 模型输出与异常

- 统一 `vision_client.extract_json()`：移除完整 `<think>…</think>` 块，优先读取 JSON 围栏，再扫描首个完整对象。向导识图、CLI observe 和辨证双件输出共用，不再各自处理一种围栏。
- `classify` 接受标点、Markdown、类别前缀和完整 think 块，仅在唯一、独立部位词命中时采用；`舌面部` 不误判为 `舌面`，多个类别回退为 `其他`。
- 响应顶层、choices、message 和 content 均做类型检查；支持多段文本 content、空 message、非 UTF-8、断流和畸形 JSON 的可诊断 `RuntimeError`，不再把 `AttributeError` / `IncompleteRead` 直接抛给页面。
- 不凭模型输出调整医学规则。图片尺寸限制、EXIF 清理、上传文件头及照片生命周期属于 B16 的 F58/F59 等任务，本批未宣称完成。

## 验证与边界

- 使用临时 `.env`、合成图片、假 key、mock 和本机临时 HTTP 服务；未调用真实模型、读取真实配置/健康记录或执行真实上传。
- 回归覆盖 CLI `.env` 全参数、并发配置成对、清 key 零调用、同源/换源 key、file:// 拒绝、跨源重定向不泄密、响应限量、滴灌总超时、有限重试、BOM/引号/非法换行、环境锁定、JSON 前置文本和报告额度。
- 测试 mock 统一为 `web.safe_fetch.urlopen`，共享 fixture 默认拒绝未 mock HTTP；只有本机临时 HTTP 服务的用例显式放行。
