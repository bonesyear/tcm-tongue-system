## 2. 默认禁用与副本启用

新 clone 默认不读取、不索引或展示外部旧目录，即使环境中存在旧根，也不会自动恢复旧内容。该行为不删除外部文件。

统一由知识库配置解析层处理：类别状态、旧报告兼容读取、候选检索和缓存都遵守默认规则。实际 `data_root` 会随配置传入，程序管理副本不会被误判为外部库。

设置页导入 ZIP 后，`<TCM_DATA_ROOT>/private_kb/<类别>/` 自动启用，不需要额外配置。每次上传只重置本类旧副本并清除停用标记；失败按事务前字节恢复配置和目录，外部源文件和其他类别不变。

公开和私有说明均只介绍默认禁用与副本启用，不包含外部恢复开关的使用说明。私有仓 README 已包含其他机器下载、整库/分类复原和 ZIP 导入步骤。
