# B17 趋势、检索、选档与性能（v1.14.0）

**日期**：2026-10-28
**范围**：F12、F13、F14、F18、F19、F20、F23、F29、F30、F82、F83、F88、G27、G29、G30。只修正工程语义与检索/加载路径，不改变医学权重、红线分类、评分或剂量策略。

## 1. 趋势输出契约

`compute_dimension_deviation_detail()` 的各维度 `first/last` 明细新增 `observed`，与已有 `score/max/n` 并列。`n` 只表示异常项数；`observed` 才表示该维度存在有效观测。全正常的已观测记录因此可以显示稳定，而不再被误报为未拍摄或未解析。

`describe_trend()` 新增可选 `first_observed/last_observed`；周报内部已传入。直接调用且不传这两个参数时保留旧 `n` 兼容行为，调用方不应再把正常 0 分自行解释为无观测。

- 非舌维度 `metric_name="累计分"` 时，累计分下降且异常项数不增即可报减轻，不要求最重单项同时下降。
- 舌诊最重单项及原有双门槛不变。
- 合法日期的 `week_id` 改为滚动七天窗口的 `start_date_end_date`，例如 `2026-10-19_2026-10-27`。同日窗口为 `2026-06-25_2026-06-25`。
- 非法日期仍保留 `YYYY-W00` 和 stderr 告警，文件名继续附带安全化的原日期，避免静默覆盖。

## 2. 检索与词典

- `src/retrieval/kb_paths.py` 统一知识库路径。相对 `TCM_KB_ROOT` 按仓库根而非调用时的当前工作目录解析；默认词典随知识库根变化。
- RAG 缓存键使用归一化绝对路径，实例缓存和索引构建都有锁，模块级入口复用 dispatcher 的共享实例。运行中修改知识库仍不会自动重建索引；重启进程或按既有内部缓存约定清理后重建。
- TF-IDF 多词查询至少命中一个多字符 token，且余弦不低于 0.2；embedding 采用相同分数下限。AND 的 RAG 补充结果先过滤低分，再以真实文件核验全部展开条件，保留项附带查询条件标签。
- 不再对无词法重合的 TF-IDF 查询强行返回“语义相关”结果。配置可用的本地 embedding 时才提供语义补检，医学相关性仍不由分数保证。
- 非 UTF-8、失效文件与 `.md` 目录不会中断全库检索，失败时 stderr 告警。分隔线不生成 chunk；超长行按 500 字切分；摘录为与查询 token 重合度最高的真实正文行及其实际行号。
- 词典使用 UTF-8 BOM 兼容读取；PyYAML 走 `BaseLoader` 保留字符串标量，嵌套对象等异常结构不被静默字符串化。缓存加载失败告警并退回空词典；直接 `load_map()` 仍严格报告读取/格式错误。
- `expand_many()` 分开去重全部检索词与实际新增同义词；同义词若同时是另一个原查询词，不重复标为新增同义词。

## 3. 每日选档与缓存

`src/daily_files.py` 是 Web、趋势与周报共用的扫描/选档入口：

1. 一次 `os.scandir` 按日期分组，大小写不敏感识别 `analysis` 与 `.json`。
2. 排除 `.bak`、`copy`、`tmp`、`_旧格式`、`副本`、`备份`、`快照`、`_backup` 和 `(数字)` 等副本，不跟随目录或文件软链。
3. 精确规范名 `{date}_analysis.json` 优先；否则选 mtime 最新的候选，多候选打印全部候选和选用者。
4. `list_dates()` 与 `select_daily_file()` 使用同一映射，不再各自拼接 glob。恢复 fallback 与按日期清理备份也直接遍历目录，支持包含 `[1]` 的路径。

目录缓存按绝对路径和目录 mtime/size 失效。摘要缓存额外按所选文件的 mtime/size 失效；首页 `list_summaries(..., limit=7)` 只计算需要的最近摘要，月历复用相同摘要。坏 JSON 不作为趋势“最近一次记录”的回跳目标。
