# 食疗知识库分层重建与数量出处校验迁移（2026-11-06）

> 本文是公开工程迁移记录，不含私有知识库正文、健康记录、密钥或原书文件。
> 决策来源：项目所有者在食疗溯源审查后明确要求“根据此报告，进行知识库的补建”。本次实施不等于完成医学标定或专业医学审核。

## 1. 变更范围

本次同时处理私有食疗知识库、综合库中的食疗副本、报告提示词、本地速览和写入校验。体质与方剂正文未改，评分、红线、置信度和方药剂量权限未改。

新食疗库由 1 份旧食疗 Markdown 调整为 6 份分层资料：

| 分层 | 内容 | 来源定位 |
|---|---|---|
| 经典方证食忌 | 桂枝汤、麻黄汤、当归生姜羊肉汤、乌梅丸的短引文及边界 | 本地《经方探源》抽取文本行号 |
| 食药物质与安全 | 9 种新增食药物质、过敏、用药禁忌、服药时间及数量规则 | 国家卫健委 2023 年第 9 号公告、国家中医药局公开说明 |
| 成人高血压 | 指南证型原则及 12 条食养资料 | 《成人高血压食养指南（2023 年版）》正式 PDF |
| 成人高脂血症 | 六类指南证型的 8 条食养资料 | 《成人高脂血症食养指南（2023 年版）》正式 PDF |
| 成人糖尿病 | 4 条食养资料 | 《成人糖尿病食养指南（2023 年版）》正式 PDF |
| 儿童青少年生长迟缓 | 以 8 岁学龄儿童为例的 9 条食养资料 | 《儿童青少年生长迟缓食养指南（2023 年版）》正式 PDF |

共 33 条官方食养方。每条的方名、指南证型、出处页码、原材料、制法、用法及已列禁忌位于同一完整检索段落，避免只命中标题而漏掉数量或限制。指南证型不改写为六经、六病、四证或九种体质。

本次未取得《中医药膳学》《中医食疗学》的可用正文，未凭书目、目录或模型记忆生成教材条目。新库是已核验资料的核心集，不宣称覆盖所有体质、疾病或食养场景。

## 2. 退出与备份

旧库中的九种体质食疗映射、无可靠出处的食疗化经方及现代克数、方类统一食谱和绝对化服药通例退出自动检索，不以“待审资料”名义继续参与报告。

导入前完整备份当前食疗副本、综合库食疗副本、综合 README 和别名词典，备份目录为 `.kb-reset-backup-diet-rebuild-20261106-83b41fcd66/`。该目录及新旧 ZIP 均不进入 Git。

食疗专用包和综合包均通过系统真实 `import_kb()` 流程导入；保留现有根路径、启停状态和其他类别，不改写 `.env`。综合导入保留三个分类专用目录，食疗正文与综合副本逐字节一致。新包输出在 `private/kb-packages/`，暂存与原文 PDF 留在公开仓之外或 Git 忽略目录。

## 3. 报告与本地速览迁移

- `templates/adaptive_analysis_prompt.md` 删除“amount 必须量化”和“库内具体分量优先照引”的旧规则。现在只有同一条候选中的原始数量、单位、制法和频次才可引用；无法完整照引时填“未提供”，不得跨条拼接或凭经验补数字。
- 高血压、高脂血症、糖尿病等指南方，必须有相应疾病专业评估且指南证型一致；不得仅凭照片、四证或九种体质推定。成人方与儿童方不得互相套用，禁忌与专业指导条件必须随条目保留。
- `web/local_report.py` 的旧 `DIET_MAP` 改为单一 `DIET_SAFETY` 边界。四证聚类不再直接输出旧食材组合，页面只提示均衡规律饮食及出处要求，不把四证改名为疾病或指南证型。
- `web/report_store.py` 新增 `_diet_output_error()`：具体食疗数量必须和同一条完整候选的方名、原始材料或用法对应。无候选、改克数、跨方拼接、只写食材名规避方名、缺数量标记或字段形状错误均拒绝保存。明确“未提供”不视为剂量。
- 数量核对只做定向空白、全角数字和连接符归一，不对整串做 NFKC。匹配仅限食疗类别和完整 `食疗资料｜…` 候选，不用方剂候选证明食疗数量。

历史记录不被重写。知识库内容版本和提示词哈希变化会触发既有报告过期机制；旧报告中的历史内容不冒充本次已核证资料。

## 4. 可回溯证据与限制

- 对官方 PDF 保留文件 SHA-256、实际页数和页码锚点；对 87 处材料、制法、用法及经典引文执行归一化原文比对。
- 专用 ZIP 为 9 个文件、6 份可检索 Markdown；综合 ZIP 为 15 个文件、12 份综合区可检索 Markdown，另保留三个专用子库。
- 33 条官方食养方均有明确出处。含试点期附加限制的方例本轮未纳入核心集；未收录不表示否定原指南，也不表示其余条目适合所有使用者。
- 分类专用库与完整综合源包完成 34 组实际候选差分，覆盖旧别名、新食养资料、经典食忌及旧无出处词组，命中内容、顺序、类别和报告输入全部一致；食疗与综合副本使用同一合并词典。
- 食疗出处、真实报告路由、本地速览及知识库状态相关聚焦 92 项通过；最终全量 1125 项通过、1 项跳过，治理清单 157 项通过，`git diff --check` 通过。真实模型调用为 0。
- 数量出处校验是工程防错，不是临床审核。它不能判断资料是否适用于具体个人，也不证明疗效、安全性或医学准确率。
- 后续取得合格教材正文后，应按实际版本逐条增补，保留原文、改编和项目说明的区别；不得为了填满九种体质而生成新方。

## 5. 回滚

先停止写入，再用备份中的旧专用包和综合包经相同导入流程恢复；恢复时保持当前配置快照，避免误改其他类别或启停状态。若只需回滚程序行为，恢复本分支改动前的提示词、`local_report.py`、`report_store.py` 和 `record.html`，并使知识库及报告缓存失效。

回滚不应删除备份、原始 PDF 或审查记录。任何配置写回失败都应同时恢复配置和目录，不得只报告成功。
