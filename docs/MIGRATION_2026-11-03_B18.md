# B18 前端交互、可访问性与时间口径（v1.14.1）

**日期**：2026-11-03
**范围**：F73、F75、F76、F77、F78、F79、F80、F81、F89、G2、G3、G6。仅修正工程交互、展示与日期语义，不改变医学权重、红线分类、评分或剂量策略。

## 1. 请求、开关与在途状态

- 新增 `POST /settings/toggle`，仅接受 `target=vision|llm` 和布尔 `enabled`。服务端只更新对应的 `VISION_DISABLED` / `LLM_DISABLED`；环境变量锁定返回 409，非法输入返回 400，解码/写入失败不会显示成功。
- 设置页不再序列化整张表单来切换模型。前端检查重定向、HTTP 状态、JSON Content-Type 和返回的开关值；失败恢复原开关状态，并在页面提示。
- 向导 `postJSON()` 自动携带当前 `STATE.date`，统一检查响应类型和错误；跳过、问诊、复核修正、手动录入与清除都有可见错误出口。
- 上传回调固定发起时的部位索引。当前部位识图进行中禁止重复上传和跳过；任何上传进行中禁止提交。提交及危险确认请求有在途锁，失败恢复，成功跳转前保持禁用。
- 危险复核继续使用原生 `<dialog>`、原生焦点约束、Esc 和返回复核，不重复添加手工焦点陷阱或冗余 ARIA 角色。

## 2. 告警、窄屏与键盘

`web/static/js/feedback.js` 将成功响应中的 `warnings` 存在当前标签页的 `sessionStorage`，详情页读取一次后移除，以文本节点显示，不把警告放入 URL 或执行其中的 HTML。存储不可用时退回即时提示。

- 首页标题改为“最近记录”，显示年份；窄屏记录行改为可收缩网格，避免固定宽度撑出 375px 页面。
- 全局窄屏网格使用 `minmax(0,1fr)`；设置密钥行允许换行；趋势头部、周导航和趋势文本有窄屏布局。
- 三个 ECharts 实例集中管理，窗口 resize 后经短延时逐一调用 `resize()`。
- 修正按钮和模型开关有 `:focus-visible` 轮廓；模型开关保留原生 checkbox 与明确名称，不使用透明隐藏破坏键盘/辅助技术识别。
- 文件输入不再 `display:none`，保留原生文件选择能力，父容器显示焦点。问诊再次点击已选答案会调用现有空答案删除接口，只撤销本题。

## 3. 日期与时区

新增 `web/time_utils.py`，使用标准库 `ZoneInfo`。`TCM_TIMEZONE` 接受 IANA 名称（例如 `Asia/Shanghai`）；未设置时使用系统时区，无效值 stderr 告警并回退系统时区。Web 可从当前 `.env` 快照读取，CLI 可使用同名环境变量。

- 首页、趋势、向导、周报默认日期统一使用该口径。
- 新记录 `timestamp`、修正/恢复 `corrected_at`、修正审计和报告 `generated_at` 使用带偏移的 ISO 字符串。旧 naive 时间戳不批量改写、不擅自解释为 UTC。
- `assemble_record()`、`update_observation()`、`restore_original()` 和 `generate_and_store_report()` 新增可选时区参数；旧调用默认系统时区，Web 调用显式传入当前配置。
- 向导所有 POST 携带会话日期；只允许恢复已存在且距当前不超过一天的草稿。次日打开向导会显示最近草稿的日期和新建出口；提交以草稿日期为准，照片、草稿、记录保持同一天。
- 本机与服务器日期不一致时显示实际日期和本次会话落档日期；使用本机年月日，不用 UTC 的 `toISOString()` 代替本地日期。
- 连续记录从今天起算；今天未记录时从昨天宽限起算。未来日期不影响连续记录、本周天数或本周平均。本周统计最多只需七条摘要，连续天数可结合全部日期计算。
- 清单文案、模型可选说明、welcome 关闭模型后的落点、失效文档链接和 `KNOWN_ISSUES` 维护约定已修正；CHANGELOG 旧 `Unreleased` 段归入既有版本结构，pre-push 增加同类检查。

## 4. 验证与边界

- `tests/test_frontend_time.py` 使用临时目录、有效合成图片、假 key、可控时钟和 mock；覆盖开关单字段写入/失败不落盘、跨午夜提交、时区偏移、草稿恢复、连续统计、Markdown 与前端契约。
- 真实 Flask 响应中的 wizard/settings/record/trends 共 6 段内联脚本通过 `node --check`；`feedback.js` 独立检查。
- 内置浏览器使用独立临时服务完成：设置成功及失败回滚、慢识图期间切步后仍归属舌面、单次提交、跨页告警、375px 首页/趋势/设置和空格键开关。所有截图和文件均为合成测试产物。
