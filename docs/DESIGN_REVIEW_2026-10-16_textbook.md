## 一、舌态与危重舌象（教材 p104–117 / L740–873）

**舌态**：教材六种病理舌态 = 痿软/强硬/歪斜/颤动/**吐弄/短缩**。
系统选项缺 2 项（L758/L760）：

| 缺失项 | 依据 | 备注 |
|---|---|---|
| 吐弄舌 | L758「舌伸口外不即回缩为吐；微露即收为弄」（p105） | 心脾积热/动风 |
| 短缩舌 | L760「舌体卷短、紧缩，不能伸长」（p105–106） | **系统危险信号 tongue_rigid 的体征名就是「舌体短缩强硬」——选项里却没有短缩，用户想报红线体征都选不到** |

**危重舌象**：教材附篇共 10 项（L869–873 / p117），系统 DANGER_FLAGS 只覆盖
镜面舌、舌强语謇 2 项，缺 8 项：

| 缺失危重舌象 | 依据（L871–873） | 主病 |
|---|---|---|
| 猪腰舌 | 舌面无苔如去膜猪腰 | 胃气将绝 |
| 砂皮舌 | 舌粗糙有刺如沙鱼皮 | 津液枯竭 |
| 干荔舌 | 舌敛束无津形如干荔肉 | 热极津枯 |
| 火柿舌 | 舌如火柿色 | 内脏败坏 |
| 赭黑舌 | 舌质色赭带黑 | 肾阴将绝 |
| 瘦薄无苔舌 | 舌体瘦小薄嫩光而无苔 | 胃气将绝 |
| 囊缩卷舌 | 舌体卷缩兼阴囊缩入 | 厥阴气绝 |
| 蓝舌而苔黑或白 | 舌质淡紫转蓝、苔转黑或白如霉点 | 病危重 |

（系统现有戴阳/肤冷脉微/大肉已脱/急性黄疸/中风/狐惑/阳明危重/脱阳前兆
均非教材危重舌象条目，出自其他篇章，不冲突。）

## 三、望诊维度完整性（p050–103）

教材有望诊而**系统完全无采集通道**的整类，按静态照片可判性分两档：

**照片不可判（不补是正确设计，建议写进文档定稿）**：
望神（p050–52，需病程对照与动态综合）、望态（p063–66，动态过程）、
口形六态（p075，动态）、鼻内病变（p074，发作事件/深藏）。

**照片可判但系统未采**（候选扩展，非缺陷——系统定位是六维精简通道）：
望形（胖瘦体质，p060–63）、望发（p068–69）、特殊面容（p069）、
目形/目态（眼窝凹陷/瞳孔/睑废，p071–72）、口腔黏膜病变（口疮/鹅口疮，
p074–75）、齿龈（p076）、咽喉（p076–77）、颈项（瘿瘤/瘰疬/颈脉怒张，
p078–79）、躯体畸形（p079–83）、四肢形态（p083–85）、皮肤病灶细分
（丹毒/白斑/斑疹/疮疡，p088–91）。望二阴（p086–88）因隐私不宜自拍采集。

## 四、处置建议（按优先级，均需主人拍板）

1. **P0 舌体动态选项补「短缩、吐弄」**——web 层 FIELD_OPTIONS 一词表改动，
  其中短缩直接关联既有红线 tongue_rigid，属于堵洞。
2. **P1 DANGER_FLAGS 增补危重舌象 8 项**——可判读性需逐项过（砂皮/干荔/
  火柿/赭黑/瘦薄无苔照片可判；猪腰/蓝舌可判；囊缩卷舌涉及隐私，建议
  仅作文本警示不采集）。
3. **P2 问诊增补「汗出时间特征（自汗/盗汗/绝汗）」1 项**——绝汗直接支撑
  脱阳前兆红线；其余缺类（疼痛性质/妇女经带/小儿）涉及问诊骨架扩容与
  模板契约变更，建议另立议题。
4. **P3 文档定稿**「照片不可判四类别」（望神/望态/口形/鼻内）——把第
  三类结论写进 user-guide 或 AGENTS.md，防止后续 Agent 误开新维度。
