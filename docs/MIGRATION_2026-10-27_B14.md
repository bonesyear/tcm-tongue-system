# B14 记录、日期、输入与文本规范化（v1.13.6）

**日期**：2026-10-27
**范围**：F6、F7、F9、F10、F66、F67、F68、F69、F72、G5、F27、G14–G20。只修数据模型、输入边界、读取容错和相应界面，不改变医学权重、预警分类、红线规则或剂量策略。

## 1. 日期与坏档读取

- 记录以 URL/文件名日期为身份；内部日期不一致时告警并按文件名读取，不写往另一天。非法日历日期不能靠字符串格式检查进入记录页。
- `web/date_utils.py` 统一合法日期、月份和边界加减；月初、年末和 `datetime` 极限不再溢出，非法 `m`/`week` 回落到可用页面。
- 非 UTF-8、非对象 JSON 和异常嵌套节点读取时降级并告警；向导坏草稿保留 `.corrupt`，不静默丢弃原文件。
- 报告的 `structured` 在落盘前检查：`three_views`/`four_patterns` 为字符串字典，`six_diseases`/`core_pathomechanism` 为字符串，饮食/起居为对象；详情读取对异常结构降级，不让一份坏报告锁死页面。

## 2. 记录与问诊契约

- A/B/C 仍由 `DailyRecord` 识别。空容器、全部维度节点非对象的 B 容器不再遮蔽完整 A 记录；非字典维度节点告警并降级，结构问题由 validator 报告。
- 问诊统一经 `get_inquiry_answers()` 读取 `{asked: true, answer}` 和形状 C 的扁平答案，报告、禁忌核对和覆盖计数使用同一来源。分母固定为 **17**；旧缓存 `total` 不一致时告警，不再显示为当次契约总数。
- 形状 A 模板补齐巩膜颜色、下睑颜色与 17 个问诊键；枚举与注册表对齐。下睑颜色采用注册表的“淡黄／苍白／淡白”。
- “未拍摄（用户声明正常）”的全/半角、空格、零宽及句末标点变体只读兼容，不计覆盖，不能作为实测值写入；与真实观察并存时不吞掉真实观察。
- 报告中的外部文本按单行、限长 JSON 字符串行输出；不能借换行注入伪指令。限长和展示规范化不是医学判读或医学标定。

## 3. 文本规范化

- `src/textnorm.py` 只删除 Cf/零宽字符和 CJK 间空白，对康熙部首、兼容表意文字及小型繁简映射做定向规范化；不对整串盲目 NFKC。
- 问句和选项通过 `canonical_option()` 比较全/半角问号、括号，写回时保留注册表中的原选项。例如“厥冷（冰冷）”仍保留注册表的全角括号。
- 评分与预警的否定分析把“不规则／不均匀”等构词与真正否定分开，不再让“剥脱”“深裂”“厚腻”被“ 不 ”误判为否定。

## 4. 修正与手动录入

- `records_store.validate_field_value()` 统一非空字符串、最多 64 字、禁止换行、声明/无法判读占位、封闭选项和绝对测量来源校验。提示词中的合法正常词也可写入，返回注册表原值。
- `/record/<date>/field` 的 `action=set|clear` 明确区分保存与清除。正式清空必须发送 `action=clear`，不能以空字符串代替；清除也保留 `correction_audit`、自动备份、validator 和重评分。
- 向导手动录入不再用 `str(...)` 把数字、数组、对象或 null 转为医学文本；草稿修正沿用空字符串撤销，正式记录使用显式清除按钮。
- 问诊入口校验题目与答案类型、长度、换行和封闭选项；半角问号可匹配，前置题改为“都不明显”会清除依赖的汗出答案，清空问诊后页面仍可用。

## 5. 识图输出分流

- 顶层接受对象或单元素对象数组；后者在观察证据中记录 `model_output_shape=single_item_array`。空数组、多元素数组、字符串或数字顶层直接拒绝。
- 字符串列表用“、”拼接；bool、数字和嵌套异常叶子保留在 `_raw`，以 `_type_errors` 单列类型问题，不与未知键 `unmapped` 混合。
- 已知键的词表外字符串同样保留在 `_raw`，以 `kind=vocab` 要求复核，不写正式观察或已确认观察元数据。合法值继续保留 raw、规范化 value 与采集能力检查。
- `点刺依据`、`舌体.点刺依据`、`耳道分泌物` 进入独立 `_notes`，不进入 `_raw`、观察元数据或红线扫描；`_raw` 的既有预警扫描语义不变。
- `危重舌象` 的布尔对象只在值为 `true` 时形成对应标志，`false` 不形成观察；非布尔值保留原值并要求类型复核。
- `/wizard/photo` 返回 `type_errors`，前端以文本告警展示未知键和异常字段，不把异常值拼入 HTML。

## 6. 验证与边界

- 使用临时目录、合成 fixture/图片、假 key 和 mock；不读取真实 `.env`、健康记录、照片或历史病案，不调用真实收费模型。
- 完整测试数量及页面/脚本验收见 `CHANGELOG.md` 的 v1.13.6 条目。实际页面使用独立临时数据根和禁用模型的本地服务。
- 本批没有进行真实医学标定、真实多设备、真实厂商模型或公网验证，也不以 welcome/未标定声明替代输入闸门。
- B13 的 LOW/MEDIUM 公式与剂量闸门、B15 的红线裁决生命周期、B16 的图片文件头和生命周期尚未启动，不在本批宣称完成。
