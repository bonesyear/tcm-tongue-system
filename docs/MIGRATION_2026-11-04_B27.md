# B27 统一视图一致性与缓存清理（v1.20.17）

**日期**：2026-11-04
**范围**：修复统一检索视图的 README 差异、特殊别名丢失、文件/目录冲突异常和临时根缓存累积。保留 B26 的正式调用链、类别闸门和候选语义，不修改知识库正文或医学规则。

## 1. README 与检索层一致

现有 `grep_search` 与 RAG 只排除精确文件名 `README.md`。统一视图复制阶段此前使用大小写不敏感比较，导致小写 `readme.md` 原库可检索、合并后消失。现复制层同样只排除精确 `README.md`，不再静默改变原库语料范围。

## 2. 别名不经过临时 YAML

多根词典仍按根目录确定顺序合并，键内别名去重并保留原有键数、每键别名数上限。合并结果通过 `syn_map` 直接传给现有 `retrieve()`，不再生成临时 `synonym_map.yaml`。

这样保留加载器已经接受的键和值，包括含 `#` 的词条，不会因无引号重写而被当作注释，也不引入新的 YAML 依赖或另一套转义规则。源词典加载、校验和错误语义不变。

## 3. 路径冲突与缓存生命周期

- 同路径不同内容仍明确拒绝，不静默覆盖。
- 文件与目录双向类型冲突统一转为带相对路径的 `ValueError`；真实权限错误不按类型冲突吞掉。
- 临时视图在 `finally` 中调用 `invalidate_kb_caches()`，清理本临时根的文件行、词典与 RAG 缓存。成功、重复调用及检索后异常均覆盖；共享同一综合根直接复用的缓存不误清。
