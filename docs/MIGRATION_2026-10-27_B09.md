# B09 测试隔离与可验证性基线（v1.13.2）

**日期**：2026-10-27
**范围**：F84–F87 的测试隔离、关键测试缺口和 mock 质量。本批只修改测试与测试协作文档，不改变业务行为。

## 隔离契约

`tests/conftest.py` 的 autouse fixture 为每项测试建立独立环境：

- `data/`、`records/daily/`、`records/weekly/`、`charts/` 全部位于该项测试的临时目录；同步 patch `src.paths` 及 `generate_weekly_report` 已缓存的目录常量，防止 import 时旧路径残留。
- `HOME` / `USERPROFILE` 指向临时 HOME；清理 `VISION_*`、`LLM_*`、`WEB_*`、`TCM_*` 和 `DASHSCOPE_API_KEY`，测试内再用 monkeypatch 设置所需值。
- `envfile.read_env` / `write_env` 遇到临时目录外的路径直接抛出 `PermissionError`；`vision_client._read_env_text` 对临时目录外路径按不存在处理，避免仓库 `.env` 和作者 profile 配置被静默使用。
- `tests/test_web_app.py` 的所有 Flask 创建路径显式使用临时 `data_root`。真实 `.env` 越界拦截自检出正式测试文件，确保 pytest 收集执行，而不是只放在不被收集的 conftest 函数中。

新增测试必须使用临时数据、临时 HOME 和 mock；不得依赖真实配置、健康记录或外部模型。

## 测试质量修复

- `tests/test_web_wizard.py` 的识图 mock 改为只替换 `vision_client.call`，真实执行 `observe_photo` 的 JSON 解析。另验证围栏 JSON 可识别、非 JSON 返回 502 且保留本次上传。
- 报告测试捕获真实 `llm_client.chat` 调用参数，直接检查用户输入中的问诊、分母和禁忌核对，以及完整系统模板，不再用另调函数替代调用链。
- 知识库报告引用与 RAG 结果改为非空必需断言，不允许检索退化为空时测试照样通过。
- 新增 14 个局域网写端点的无口令拒绝检查、伪造 boot cookie、非法上传扩展名、非法日期和路径穿越测试。安全策略本身的完整修复属于 B11，不把测试覆盖增加误写成安全行为已全部改变。
