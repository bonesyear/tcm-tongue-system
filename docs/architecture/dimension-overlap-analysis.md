# 六维度望诊拍摄重叠分析与优化方案

> **架构分析文档** | 版本 v1.2.0 | 日期 2026-06-19
> **问题**: 头面诊内部包含面、唇、鼻三个子域，区域高度重叠；目诊、耳诊、手诊、皮肤诊与头面诊也存在部分视角重叠
> **目标**: 在 v1.2.0 六维体系（舌/头面/目/耳/手/皮肤）下消除冗余拍照、优化用户体验，同时保留安全红线所需的独立特写

---

## 一、六维度体系与拍照边界

v1.2.0 将拍照维度统一为 **6 个**：

```
┌─────────────────────────────────────────────┐
│ 1. 舌诊（舌面 + 舌底）—— 2 张照片            │
│ 2. 头面诊（面域 + 唇域 + 鼻域）—— 1 张面部照 │
│ 3. 目诊（白睛、巩膜、眼睑、目眶）—— 1 张眼部照 │
│ 4. 耳诊（耳色、耳轮）—— 1 张侧耳照           │
│ 5. 手诊（掌色、掌温、甲床）—— 1 张手掌照     │
│ 6. 皮肤诊（肤色、甲错、黄汗、水肿）—— 1 张皮肤照│
└─────────────────────────────────────────────┘
```

其中**头面诊**是 v1.2.0 的核心合并维度：将原本分散的“面诊、唇诊、鼻诊”合并为一张正面面部照，同时保留**目诊**作为独立维度（安全红线需要）。

## 二、重叠分析

### 2.1 各维度观察指标与拍照可行性

| 维度 | 子域/指标 | 判读粒度 | 是否可与其它维度共享照片 | 是否必须独立拍摄 |
|:---|:---|:---|:---|:---|
| **舌诊** | 舌质、舌苔、舌形、舌下络脉 | 微观 | ❌ 口腔内特写，无法共享 | ✅ 必须独立 |
| **头面诊** | 面色、面部水肿、光泽 | 宏观 | ✅ 头面诊主照片 | ❌ 不需要额外照片 |
| | 唇色、唇润燥、口周 | 中观 | ✅ 同一张面部照 | ❌ 不需要额外照片 |
| | 鼻色、鼻翼煽动、鼻衄 | 中观 | ✅ 同一张面部照 | ❌ 不需要额外照片 |
| **目诊** | 白睛颜色、目赤、眼睑浮肿、目眶黯黑、巩膜黄染 | 中观-微观 | ⚠️ 明显异常可在头面照中粗筛，轻度/早期不可靠 | ✅ **必须独立眼部特写（安全红线）** |
| **耳诊** | 耳色、耳轮润枯 | 中观 | ❌ 需要侧面角度 | ✅ 必须独立侧耳照 |
| **手诊** | 掌色、掌温、甲床、手掌瘀斑 | 中观 | ❌ 需单独伸手取景 | ✅ 必须独立 |
| **皮肤诊** | 肤色、甲错、黄汗、水肿、干燥 | 中观-宏观 | ❌ 需暴露前臂/小腿皮肤 | ✅ 必须独立 |

### 2.2 核心发现

**可以从一张面部全景照共享的指标：**

```
正面面部照（30cm，手机主摄）可同时覆盖：
┌─────────────────────────────────────────────┐
│ ✅ 头面诊（100%）：面域 + 唇域 + 鼻域        │
│ ⚠️ 目诊（粗筛 60%）：明显目赤/黄染/浮肿可见  │
│    └─ 轻度巩膜黄染、轻微目赤、轻度卧蚕       │
│       需要 15-20cm 眼部特写才可靠            │
└─────────────────────────────────────────────┘
```

**必须独立特写的指标：**

| 指标 | 为什么需要独立 | 临床重要性 | 缺失后果 |
|:---|:---|:---|:---|
| **舌诊全部指标** | 口腔内细节无法从面部照获取 | 极高 | 丢失水火气血核心证据 |
| **巩膜黄染（轻度）** | 早期黄疸在全景照中仅占极少像素 | ⚠️ **极高**——安全红线「急性肝胆重症」 | 漏诊早期肝胆重症 |
| **目赤（轻微血丝）** | 细小白睛血丝在全景照中不可见 | 高 | 少阳病与阳明里热鉴别困难 |
| **耳轮润燥、耳色** | 需要侧面光线与角度 | 中 | 少阳中风、津液判断辅助证据丢失 |
| **手掌温度/甲床** | 无法从任何面部照推断 | 高 | 表里阴阳判断关键证据丢失 |
| **皮肤甲错/黄汗/水肿** | 需暴露四肢皮肤 | 高 | 太阴中风、瘀血、水饮证据丢失 |

## 三、安全红线与特写策略

### 3.1 安全红线触发所需的拍摄条件

| 安全红线 | 主要依赖维度 | 是否需要特写 | 说明 |
|:---|:---|:---|:---|
| 戴阳证（面红如妆 + 手足厥逆） | 头面诊 + 手诊 | ❌ | 头面照可见“红如妆”，手诊确认“厥冷” |
| 肤冷 + 脉微 | 手诊 + 问诊 | ❌ | 手诊掌温“厥冷”可提示 |
| 大肉已脱 + 大骨陷下 | 皮肤诊 + 问诊 | ❌ | 皮肤诊与形体观察结合 |
| 舌体短缩强硬 | 舌诊 | ✅ | 舌面/舌底特写 |
| 舌质紫暗 + 苔焦黑干裂 | 舌诊 | ✅ | 舌面特写 |
| 镜面舌 + 极度消瘦 | 舌诊 + 皮肤诊 | ✅ | 舌面特写为主 |
| 巩膜黄染 + 皮肤黄如橘皮 | 目诊 + 皮肤诊 | ✅ **眼部特写必须** | 轻度黄染需眼部特写 |
| 口不能言 + 身体不收 | 头面诊 + 手诊 | ❌ | 静态照仅能提供部分线索 |
| 咽干 + 吞咽困难 + 面目乍赤乍黑 | 头面诊 + 问诊 | ❌ | 面目变化由头面照覆盖 |

### 3.2 目部特写触发条件

当满足以下任一条件时，系统应提示用户补充目部特写：

1. 头面照中眼部区域不清晰（光线/角度问题）
2. 头面诊目域粗筛发现“可疑黄染”或“不确定”
3. 辨证涉及少阳病/肝胆方向，需要精确目赤判据
4. 安全红线 #7（急性肝胆重症）存在任何可疑线索

| 指标 | 30cm 全景照 | 15cm 眼部特写 | 结论 |

| 目眶黯黑 | 可满足 | 更精确 | 可选增强 |

## 五、优化方案

### 5.1 推荐拍摄套餐

| 套餐 | 所需照片 | 覆盖维度 | 适用场景 |
|:---|:---|:---|:---|
| **基础套餐** | 舌面、舌底、头面、手、皮肤 | 4 维 | 日常随访，快速达到 HIGH 置信度 |
| **完整套餐** | 舌面、舌底、头面、目、耳、手、皮肤 | 6 维 | 首诊或辨证复杂时使用，达到 HIGH 置信度 |
| **增强套餐** | 完整套餐 + 目部特写（15cm） | 6 维 + 目域增强 | 可疑黄疸、少阳病、眼部异常时 |

### 5.2 证据覆盖度计算

v1.2.0 置信度仍由**已覆盖的拍照维度数量**决定：

| 覆盖维度 | 置信度 | 输出内容 |
|:---|:---|:---|
| 1 个 | 🟡 LOW | 鉴别诊断列表，不给方剂 |
| 2-3 个 | 🟠 MEDIUM | 方向性辨证，给方剂类别 |
| 4-6 个 | 🟢 HIGH | 完整辨证 + 具体方剂与剂量 |

**计数规则**：
- 舌诊：舌面 + 舌底计为 1 个维度
- 头面诊：面域 + 唇域 + 鼻域计为 1 个维度
- 目诊、耳诊、手诊、皮肤诊各计 1 个维度
- 目部特写不新增维度，仅提升“目域”判读级别

## 七、总结

**v1.2.0 核心改动**：
- 诊断维度从旧版 9 维精简为 **6 维**：舌诊、头面诊、目诊、耳诊、手诊、皮肤诊
- 头面诊一照覆盖面、唇、鼻三个子域，消除同一张脸多次拍摄的冗余
- 目诊仍保持独立，以满足轻度巩膜黄染等安全红线的检测需求
- 舌诊、耳诊、手诊、皮肤诊因视角或部位特殊，仍需独立拍摄
- 安全红线 9 条与 `danger_flags` 结构完全一致

**用户体验提升**：
- 日常随访最少只需 3 个维度即可达到 MEDIUM 置信度，4-6 个维度可达到 HIGH 置信度
- 头面部拍摄从多张合并为 1 张
- 仅在疑似眼部异常时提示目部特写，避免过度拍摄

**不变的部分**：
- 许家栋经方辨证核心逻辑（三观 → 四证 → 六病）完全不变
- 安全红线优先级不变
- 问诊 15 项结构不变
