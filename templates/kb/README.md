# 分类知识库合成模板

本目录只演示三类专用包的文件结构，不含医学知识，也不是原私有知识库的副本。可将本目录复制到仓库外，再换成你有权使用并已人工核对的内容。

- `kb.yaml`：类别清单，默认 `constitution`；导入食疗或方剂前改成 `diet` 或 `formula`。
- `example.md`：非临床占位正文；保留清晰标题、来源和许可元数据的写法。
- `synonym_map.yaml`：非临床占位别名，使用顶层字符串键和缩进字符串列表。
- 本 `README.md`：只给读者看，不参与检索。

将需要导入的文件打成 ZIP（不要把本说明作为唯一 Markdown），然后在「设置 → 知识库」展开默认折叠的「子知识库」分组，在对应专用知识库卡片中上传。分类 ZIP 必须带 `kb.yaml`，且类别与表单一致。每次成功导入只覆盖本类导入副本并解除本类自身停用，不自动开启整组，不修改其他类别或外部原库。整组和本类开关均须处于启用状态，本类才参与检索和报告。

从一本中医著作整理综合包的步骤见 [`docs/kb-guide.md`](../../docs/kb-guide.md)，完整规范见 [`docs/KB_AUTHORING.md`](../../docs/KB_AUTHORING.md)。

你可以直接使用未修改的合成 ZIP 验证链路：查询 `示例口语` 应展开为 `示例规范词` 并命中 `example.md`。该命中仅证明检索工作，不表示任何医学有效性。
