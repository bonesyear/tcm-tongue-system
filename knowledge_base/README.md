# 知识库配置说明

公开仓库不再附带原结构化知识库、整理/衍生笔记或别名词典。这里仅保留配置说明，不是替代知识库，也不会生成检索证据。

## 私有知识库

完整内容已保存在仓库外的私有目录，原版权说明保持不变。公私分离不等于取得公开再分发授权，也不改变既有公开历史。

使用现有 `TCM_KB_ROOT` 指向你**有权使用的私有知识库目录**：

```bash
# Linux / macOS 示例
export TCM_KB_ROOT=/absolute/path/to/private-kb

# Windows 示例：请在系统环境变量或项目 .env 中配置绝对路径
# TCM_KB_ROOT=C:\private\knowledge_base
```

`TCM_KB_ROOT` 是部署配置，不接受网页用户输入。Grep、RAG 和默认别名词典共用此根目录；相对路径按仓库根归一化。不要把私有目录路径、原始引文或笔记重新提交到公开仓库。

未配置或目录不存在时，检索按既有降级行为返回空结果或告警，不伪造知识库引用。公开测试使用 `tests/fixtures/knowledge_base/` 中的独立合成资料，不依赖私有内容。

## 本地 ZIP 导入与自建

「设置 → 知识库」前方的「子知识库」分组默认折叠，展开后可导入中医体质辨证、食疗、方剂三类专用包，综合导入位于其后。手中只有一本中医著作时，按 [`docs/kb-guide.md`](../docs/kb-guide.md) 完成资料整理、原文复核、综合 ZIP 打包、导入和验收；目录结构与清单格式以该指南为准，完整技术约束见 [`docs/KB_AUTHORING.md`](../docs/KB_AUTHORING.md)。导入动作本身不调用模型。

整组、三个子库和综合库各有独立开关。整组停用会暂停三个子库及综合回退，但保留各子库自身选择；综合停用只暂停综合根及分类回退，不影响独立专用根。开关只控制检索和展示，不删除文件。严格分类模式与整组启停独立。

每次综合导入只覆盖 `<TCM_DATA_ROOT>/private_kb/` 这份程序管理的综合副本，保留其中的分类专用子目录，再按需写回 `TCM_KB_ROOT` 并解除综合自身停用；分类导入只覆盖对应的 `<TCM_DATA_ROOT>/private_kb/<类别>/` 并解除本类自身停用。导入不会自动开启整组或改变其他类别选择，也**不会移动、覆盖或删除上述外部私有目录**。不要把唯一原稿放进导入副本。环境变量锁定时不改 `.env`，现有根继续生效。自定义内容只参与检索与引用，不自动修改医学规则，也不是模型训练。
