# 许家栋《经方探源》——方药体系提取纲要

---

## 一、方机体系（病机与方剂对应关系）

### 1.1 核心辨证口诀

> **"病随机转，方从法出；以法统方，以平为期。"**

经方施治法则：以药势对应病势，达到"反之于平"的"阴阳自和"状态——即以药物的寒热温凉、升降浮沉，对应病势的表里、寒热、虚实。

### 1.2 三观统摄

| 三观 | 核心原则 | 临床应用 |
|------|---------|---------|
| **表里观** | 首辨表里，尤重表证 | 表邪不解则里邪永难解 |
| **正邪观** | 主辨虚实，细分胃虚 | 胃气强弱决定病传病解 |
| **津液观** | 津液一元，阴阳自和 | 卫气营血皆为津液所派生 |

### 1.3 四证体系（最小病理单位）

> "人身不过表里，气血不过阴阳；阴阳涵于津液，津液病分四部。"

| 四证 | 病名举例 | 关联方药 |
|------|---------|---------|
| **水证** | 水逆、水气、水结、淡饮、溢饮 | 苓桂剂、麻黄剂 |
| **火证** | 火逆、火邪、火气 | 白虎剂、承气剂 |
| **气证** | 气逆、气结、结气 | 桂枝剂、理中剂 |
| **血证** | 血少、亡血、瘀血、血分 | 当归剂、芍药剂 |

### 1.4 基础病机 + 复合病机 = 六病

- **基础病机**：最小而不可再分之病理单位（表束、表实、表热、里热、里燥、里结等）
- **复合病机**：以阴阳三分法归类后的六病（太阳、阳明、少阳、太阴、少阴、厥阴）
- **辨证公式**：基础病机 = "辨"，复合病机 = "病"

### 1.5 病传路径规律

```
太阳伤寒 → 病传水证（大青龙汤）、火证（大青龙汤）、气证（麻黄加术汤）、血证（葛根汤）
太阳中风 → 病传水证（桂枝加厚朴杏子汤）、火证（桂枝加葛根汤）、气证（同水证）、血证（桂枝加桂汤）
...
```
每一主证皆有水→火→气→血四条病传路径，各有对应方剂。

## 二、六病代表方

### 2.1 太阳病

#### 太阳伤寒（本病）——麻黄汤
| 药物 | 剂量 |
|------|------|
| 麻黄（去节） | 三两 |
| 桂枝（去皮） | 二两 |
| 甘草（炙） | 一两 |
| 杏仁（去皮尖） | 七十个 |

- **病机**：表束 + 表热（阳）+ 表实（津液绝对有余，凝滞在表而充盛——无汗）
- **治法**：（辛）苦温宣泄
- **正药**：麻黄
- **方效**：温表散寒，发汗除水，宣通降逆，泄越瘀血
- **病传方**：大青龙汤（水/火）、麻黄加术汤（气）、葛根汤（血）

#### 太阳中风——桂枝汤
| 药物 | 剂量 |
|------|------|
| 桂枝（去皮） | 三两 |
| 芍药 | 三两 |
| 甘草（炙） | 二两 |
| 生姜（切） | 三两 |
| 大枣（擘） | 十二枚 |

- **病机**：表束 + 表热（阳）+ 表虚（津液绝对不足，凝滞在表而涣散——表虚汗出）
- **治法**：（辛）甘温补益
- **正药**：桂枝
- **方效**：解表祛邪，调和营卫，温中降逆，解肌缓急
- **病传方**：桂枝加厚朴杏子汤（水/气）、桂枝加葛根汤（火）、桂枝加桂汤（血）

#### 太阳风寒两感——桂枝麻黄各半汤
- **病机**：表束 + 表热（阳）+ 津液半虚半实
- **治法**：太阳伤寒治法 + 太阳中风治法（合方合法）

## 三、治法法则（治疗原理）

### 3.1 六经正治法

| 病位 | 正治法 | 代表药 |
|------|--------|--------|
| **太阳表实** | 辛温宣泄（苦温） | 麻黄 |
| **太阳表虚** | 辛甘温补益 | 桂枝 |
| **阳明里热** | 苦寒清下 | 黄芩、黄连、大黄 |
| **阳明里燥** | 咸寒润降 | 芒硝 |
| **阳明外热** | 辛寒解肌 | 石膏、葛根 |
| **少阳郁火** | 苦寒清解 + 甘温补益 | 柴胡、黄芩 + 人参、甘草 |
| **太阴里寒** | 甘温温中散寒 | 甘草、干姜 |
| **太阴里虚** | 甘以补中 | 甘草、人参 |
| **少阴表寒** | 辛热解表 | 麻黄 + 附子 |
| **少阴真阳虚** | 补火助阳 | 附子 |
| **厥阴半病** | 辛开苦降（辛为主）| 桂枝/前胡 + 黄芩/黄连 |

### 3.2 阳明四法

| 法度 | 药势 | 针对病机 | 代表药/方 |
|------|------|---------|-----------|
| **苦寒法** | 寒能清热，苦能降泄 | 阳明里热为主 | 黄芩、黄连、黄柏、大黄 |
| **辛寒法** | 寒能清利，辛能开泄行散 | 里热蒸腾导致外热及里结外结 | 石膏、寒水石、葛根、升麻、丹皮 |
| **酸寒法** | 酸涌、酸泄、酸消、酸益、酸收、酸敛 | 火证兼水、兼虚、兼表 | 酸浆水、枳实、栀子、芍药、苦酒 |
| **咸寒法** | 咸能软坚散结，寒能清利攻下 | 里燥、里结 | 芒硝、硝石 |

### 3.3 辛温解表的独特地位

> **"予邪气以出路，即予病家以生路。"**

- 太阳表热用**辛温药**来解，非以寒胜热，此乃仲景独创心法
- 麻黄、桂枝、杏仁、淡豆豉为太阳表药基础
- 据表里层次和津血盈亏不同，可加生姜、苏叶、葱白等

### 3.4 太阴治下利三法

| 次序 | 治法 | 代表方 |
|------|------|--------|
| 第一法 | 温胃补虚，制化下焦 | 理中辈 |
| 第二法 | 服饵补虚，固敛下焦 | 赤石脂禹余粮汤辈 |
| 第三法 | 温渗利水，分清别浊 | 甘姜苓术汤辈 |

| **干姜附子汤** | 干姜 + 附子 | 温固里阳，补火助阳（四逆类方基础） |
| **生姜甘草汤** | 生姜 + 甘草 | 温中补益和胃（少阳/厥阴核心方干） |
| **小半夏汤** | 半夏 + 生姜 | 温胃和中，降逆化饮 |
| **甘草麻黄汤** | 甘草 + 麻黄 | 发越里水 |
| **桔梗汤** | 桔梗 + 甘草 | 散结导滞，清热消痈 |

### 5.2 经方合方法度

> **"法与法合则方与方合"**

- 合方时**剂量缩减**，非加大剂量或取最大量
- 如柴胡桂枝汤：各取小柴胡汤与桂枝汤**半量**
- 如桂枝麻黄各半汤、桂枝二麻黄一汤、桂枝二越婢一汤，皆为剂量缩减
- 经方规律：方剂药物越多，剂量越小（如侯氏黑散、薯蓣丸）

### 5.3 桂枝汤作为"五经中风基础方"

> "六病中风除阳明有'厥阳独行'之特异外，其他五经皆是以阳旦法桂枝汤为基础方干，参以本经药证。"

| 病位 | 中风主方 | 基础方干加法 |
|------|---------|-------------|
| 太阳中风 | 桂枝汤 | — |
| 少阳中风 | 柴胡桂枝汤 | 桂枝汤 + 柴胡法 |
| 太阴中风 | 桂枝加黄芪汤 | 桂枝汤 + 黄芪 |
| 少阴中风 | 桂枝加附子汤 | 桂枝汤 + 附子（重用甘草三两） |
| 厥阴中风 | 前胡（桂枝）汤 | 桂枝汤 + 前胡 + 竹叶 + 当归 |

## 六、辨证选方逻辑

### 6.1 六病辨证流程

```
症状 → 辨表里（表里观） → 辨虚实（正邪观） → 辨津液（津液观）
     → 辨水火气血（四证） → 辨基础病机 → 辨复合病机（六病归属）
     → 方从法出 → 选方用药
```

### 6.2 关键鉴别要点

#### 表里鉴别
- **小便**：自汗必审小便；小便清→病在表，小便不利→病在里
- **大便**：大便溏而下利→太阴；大便硬→阳明
- **二便如常**→救表；二便失常→救里

#### 三阴下利鉴别
| 病位 | 特点 | 渴否 |
|------|------|------|
| 太阴下利 | 自利不渴 | 口淡不渴 |
| 少阴下利 | 自利而渴 | 津液丢失更重 |
| 厥阴下利 | 自利消渴 | 津液大伤，欲引水自救 |

#### 太阳与阳明发热鉴别
| 病位 | 发热机理 | 治法 |
|------|---------|------|
| 太阳 | 卫气过强（阳气重），凝涩在表，郁滞生热 | 辛温发汗泄卫气 |
| 阳明 | 热邪火邪充盛有余，蒸腾于里 | 以寒胜热 |

#### 少阳与厥阴鉴别
| 维度 | 少阳病 | 类厥阴病 |
|------|--------|----------|
| 阴阳 | 偏于阳、表、上焦 | 偏于阴、里、下焦 |
| 核心特征 | 寒热往来 + 上焦郁火 | 寒热杂错 + 下焦饮逆 |
| 公式 | 半病阳证 + 胃虚 | 半病阴证 + 胃虚 |
| 代表方 | 小柴胡汤 | 小前胡汤 |
| 生姜量 | 三两 | 五两 |

### 6.3 选方禁忌

- **少阳中风**：严禁吐下
- **少阴里病**：禁汗、吐、下，禁利小便
- **真厥阴病**：有表证无表邪，严禁解表
- **阳明中风**：忌桂枝（"桂枝下咽，阳盛则毙"）

### 6.4 辨脉要领

| 脉象 | 提示 |
|------|------|
| 脉浮紧 | 太阳伤寒（卫阳充盛） |
| 脉浮弱/浮缓 | 太阳中风（津液不足） |
| 脉沉 | 有留饮（"脉沉者，有留饮"）|
| 脉微细 | 少阴本病（表阳真阳俱伤）|
| 脉微欲绝 | 真厥阴病（阴阳离决）|
