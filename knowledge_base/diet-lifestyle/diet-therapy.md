# 经方食疗方案（经典经方体系）

> 基于经典经方学术体系的食疗指导方案。食疗与方药同理——皆本于四气五味，归于六病辨证。食即是药，食不得法亦能伤正。

---

## 一、四气五味概述

### 1.1 四气（寒热温凉）

| 气 | 作用 | 代表食物 | 适用病机 |
|:---|:---|:---|:---|
| **寒** | 清热泻火、凉血解毒 | 苦瓜、西瓜、绿豆、芹菜 | 阳明热盛、实火内炽 |
| **凉** | 清热生津、凉润 | 梨、藕、银耳、豆腐 | 阳明津伤、虚火上浮 |
| **温** | 温中散寒、助阳通脉 | 生姜、羊肉、桂圆、大枣 | 太阴虚寒、少阴阳虚 |
| **热** | 温阳救逆、驱寒止痛 | 干姜、胡椒、辣椒、肉桂 | 少阴里寒、真阳虚衰 |

### 1.2 五味（酸苦甘辛咸）

| 味 | 归经 | 作用 | 代表食物 | 过食之害 |
|:---|:---|:---|:---|:---|
| **酸** | 肝 | 收敛固涩、生津止渴 | 乌梅、山楂、柠檬、醋 | 过酸伤胃，胃虚者忌 |
| **苦** | 心 | 清热燥湿、降泄 | 苦瓜、莲子心、蒲公英、茶 | 过苦伤津，津亏者忌 |
| **甘** | 脾 | 补益和中、缓急止痛 | 粳米、大枣、山药、蜂蜜 | 过甘生湿，湿盛者忌 |
| **辛** | 肺 | 发散行气、活血通脉 | 生姜、葱白、花椒、桂皮 | 过辛耗气，气虚者忌 |
| **咸** | 肾 | 软坚散结、润下通便 | 海带、紫菜、牡蛎、盐 | 过咸伤血，血虚者忌 |

## 二、九种体质食疗映射

### 2.1 平和质
- **适宜**：均衡饮食，五谷为养，五果为助，五畜为益，五菜为充
- **忌口**：无特殊禁忌，避免长期偏食某一味
- **推荐**：粳米粥、山药、莲子、大枣

### 2.2 气虚质（太阴方向）
- **适宜**：甘温补气——黄芪炖鸡、党参粥、山药排骨汤、大枣桂圆
- **忌口**：生冷瓜果、苦寒败胃之品、过辛耗气
- **推荐方**：黄芪建中汤食疗化——黄芪15g + 桂枝6g + 生姜3片 + 大枣6枚 + 饴糖适量 + 粳米煮粥

### 2.3 阳虚质（少阴/太阴方向）
- **适宜**：辛甘温热助阳——生姜羊肉汤、当归生姜羊肉汤、韭菜炒核桃
- **忌口**：一切生冷、寒凉之物（西瓜、苦瓜、冰饮、绿豆、螃蟹）
- **推荐方**：当归生姜羊肉汤（当归15g + 生姜30g + 羊肉250g），尤宜于少阴血虚寒厥

### 2.4 阴虚质（阳明津伤方向）
- **适宜**：甘寒润燥——银耳百合羹、雪梨炖冰糖、石斛麦冬茶、鸭肉炖藕
- **忌口**：辛辣燥热（辣椒、花椒、肉桂、羊肉、酒）、苦燥伤津
- **推荐方**：麦门冬汤食疗化——麦冬15g + 粳米一把 + 大枣5枚 + 甘草6g + 百合15g 煮粥

### 2.5 痰湿质（太阴水证方向）
- **适宜**：甘淡利湿——薏米赤小豆粥、茯苓山药糕、冬瓜汤、白萝卜
- **忌口**：肥甘厚腻、甜食乳制品、生冷助湿、过甘
- **推荐方**：苓桂术甘汤食疗化——茯苓15g + 桂枝6g + 白术10g + 甘草3g + 薏米30g 煮粥

### 2.6 湿热质（阳明水热/太阴湿热方向）
- **适宜**：苦寒清热利湿——绿豆薏米汤、茵陈茶、冬瓜排骨汤、苦瓜炒蛋
- **忌口**：辛辣燥热助火、肥甘厚腻助湿、酒酪臭恶
- **推荐方**：茵陈五苓散食疗化——茵陈15g + 茯苓10g + 泽泻10g + 薏米30g 煎水代茶

### 2.7 血瘀质（血证方向）
- **适宜**：辛温活血——山楂红糖水、当归田七炖鸡、桃仁粥、醋泡花生
- **忌口**：寒凉凝滞（冰饮、生冷）、肥腻
- **推荐方**：桂枝茯苓丸食疗化——桂皮3g + 茯苓10g + 桃仁10g + 赤芍10g + 山楂15g 煮水代茶

### 2.8 气郁质（少阳方向）
- **适宜**：辛散理气——玫瑰花茶、佛手柑、陈皮粥、薄荷茶
- **忌口**：过酸收敛（妨碍气机）、酒（虽辛散但入里化热）
- **推荐方**：小柴胡汤食疗化——柴胡苗10g + 生姜2片 + 大枣5枚 + 甘草3g + 薄荷3g 代茶

### 2.9 特禀质
- **适宜**：甘平固表——黄芪防风粥、五指毛桃汤、灵芝粉
- **忌口**：海鲜发物、异体蛋白、辛辣刺激、过敏原
- **推荐方**：玉屏风散食疗化——黄芪15g + 防风6g + 白术10g + 山药20g + 粳米煮粥

## 三、药物与食物禁忌（经方服药忌口）

### 3.1 桂枝汤忌口（《伤寒论》原文第12条）
> 「禁生冷、粘滑、肉面、五辛、酒酪、臭恶等物」

| 禁忌类别 | 具体内容 | 原理 |
|:---|:---|:---|
| **生冷** | 生食、冷饮、冰品、凉拌菜 | 寒伤胃阳，妨碍桂枝辛温发散之力 |
| **粘滑** | 糯米、年糕、肥肉、奶油 | 滞腻碍胃，阻滞气机 |
| **肉面** | 肉类（尤其肥腻）、面食过多 | 增加胃气负担，掣肘药力 |
| **五辛** | 大蒜、小蒜、韭、芸薹、胡荽 | 辛散太过，夺桂枝发散之正力 |
| **酒酪** | 酒类、奶酪、乳制品 | 酒助湿热，酪滞中焦 |
| **臭恶** | 腐败变质、气味异常之食物 | 败坏胃气，引邪入里 |

### 3.2 各经方代表忌口

| 方剂/方类 | 适宜 | 忌口 |
|:---|:---|:---|
| **麻黄汤类** | 温粥助汗（啜热稀粥以助药力） | 生冷、油腻（同桂枝汤忌口） |
| **白虎汤类** | 甘寒润燥（粳米汤、梨汁、藕汁） | 辛辣燥热、温补 |
| **承气汤类** | 清淡稀粥、蔬菜泥（通下后养胃） | 硬食、油腻、粘滑、辛辣 |
| **理中汤类** | 甘温补中（生姜大枣粥、饴糖） | 生冷、苦寒、肥腻 |
| **苓桂剂** | 甘淡利湿（薏米粥、茯苓饼） | 生冷助湿、过甜、乳制品 |
| **柴胡剂** | 清淡疏利（薄荷茶、佛手柑） | 过酸收敛、肥甘厚腻 |
| **四逆汤类** | 辛甘大热（干姜红糖水、肉桂粉） | 一切生冷寒凉 |
| **当归剂** | 甘温养血（大枣桂圆、当归炖乌鸡） | 寒凉凝滞、生冷 |

### 3.3 通用服药饮食原则
1. **服药期间忌生冷**——生冷伤胃阳，妨碍药力吸收（「胃气乃药力之车」）
2. **忌饱食后立即服药**——食满则药不得入，当食后1-2小时服药
3. **发汗剂需辅以温覆**——桂枝汤、麻黄汤等解表剂，服后当温覆取微汗
4. **下剂后忌暴食**——承气类下后，胃气尚虚，当渐进饮食
5. **补益剂忌萝卜**——萝卜破气，与人参、黄芪相恶

## 四、常见六病代表方的饮食建议

### 4.1 太阳病——麻黄汤/桂枝汤证
- **主证方向**：表实热/表虚寒，邪在表
- **饮食原则**：辛温发散，助药力达表
- **推荐**：生姜红糖水、葱白粥、热稀粥
- **禁忌**：生冷冰饮、油腻粘滑、酒类（酒虽辛散但入里化热，不宜表证）

### 4.2 阳明病——白虎汤/承气汤证
- **主证方向**：里实热/燥结
- **饮食原则**：清热生津、通腑泄热
- **推荐**：粳米汤、绿豆汤（白虎证）、蜂蜜水调决明子（承气证后）
- **禁忌**：辛辣助火、温补助热、硬食难化

### 4.3 少阳病——小柴胡汤证
- **主证方向**：半表半里，上焦郁火+中焦胃虚+下焦饮逆
- **饮食原则**：和胃降逆，忌壅滞助火
- **推荐**：薄荷姜枣茶、陈皮粥、佛手柑水
- **禁忌**：过酸（收敛碍邪）、辛辣（助上焦郁火）、生冷（伤中焦胃气）

### 4.4 太阴病——理中汤/苓桂术甘汤证
- **主证方向**：里虚寒/水湿内停
- **饮食原则**：甘温补中、淡渗利湿
- **推荐**：生姜大枣粥（理中方向）、茯苓薏米粥（苓桂方向）、黄芪炖鸡
- **禁忌**：生冷伤阳、苦寒败胃、过甘助湿、乳制品

### 4.5 少阴病——四逆汤/真武汤证
- **主证方向**：表虚寒+真阳虚，两层病位
- **饮食原则**：辛甘大热回阳、甘温利水
- **推荐**：当归生姜羊肉汤、干姜红糖水、桂皮炖牛肉
- **禁忌**：一切生冷寒凉、苦寒伤阳、发汗过度（伤津亡阳）

### 4.6 厥阴病——乌梅丸/泻心汤证
- **主证方向**：寒热杂错、虚实夹杂
- **饮食原则**：辛开苦降甘调，最难调摄——寒热食物搭配得宜
- **推荐**：乌梅山楂茶（酸收）、生姜萝卜汤（辛开苦降）
- **禁忌**：纯寒纯热极端饮食、暴饮暴食、生冷+辛辣同食
