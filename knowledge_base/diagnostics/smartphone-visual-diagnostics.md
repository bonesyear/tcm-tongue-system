## 前言：拍照+问诊——多维度辨证的数据采集体系

舌诊虽为核心望诊手段，但许家栋经典经方体系强调 **"人身不过表里，气血不过阴阳；阴阳涵于津液，津液病分四部"（L1610）**。表里之变、气血之盈虚、水火的失调，必然显现于人体的多个外显部位。手机拍照可捕捉面部（含唇鼻）、眼目、耳部、手掌、皮肤等多个维度的视觉信息，配合许家栋十五项核心问诊，构成一个立体化辨证数据采集系统。

**核心辨证逻辑链：**
```
智能手机6维拍照 + 15项问诊 → 多维度信息采集 → 四证（水/火/气/血）辨识
→ 三观（表里/正邪/津液）定位 → 六病（阴阳三分）归属 → 选方用药
```

**设计原则：**
- **拍得到的拍照**：6个可自拍的部位
- **拍不到的问诊**：15项问诊全部可跳过——系统基于已知信息做最佳辨证
- **一份证据说一分话**：有信息就深入，没信息就不编

## 一、六大拍照维度详解

---

### 1. 舌诊（舌面+舌底）—— 四证全覆盖核心窗口

**拍照方法：**
- 舌面：面对自然光，舌自然平伸，舌尖抵下唇，手机距离约20cm，对焦舌面中央
- 舌底：头后仰，舌尖用力顶上颚，手机从下往上拍，对焦舌下络脉
- 拍摄前15分钟内不吃东西、不喝咖啡茶（避免染色）

**观察指标：**
| 区域 | 指标 |
|:---|:---|
| 舌面 | 舌质颜色/荣枯/瘀斑/老嫩，舌苔色/厚薄/润燥/腻腐/剥落/分布，舌体胖瘦/齿痕/裂纹/点刺/动态 |
| 舌底 | 舌下络脉颜色/粗细/迂曲/瘀点 |

**四证映射：**
- 舌淡胖齿痕苔滑 → **水证**（水湿内停）
- 舌红苔黄燥 → **火证**（热盛津亏）
- 舌淡嫩薄白 → **气证**（气虚）
- 舌紫暗瘀斑 → **血证**（瘀血）

**鉴别诊断价值（Tier 1 — 核心）：**
- 水火气血第一窗口，四证全覆盖
- 太阴/阳明/少阴核心判据

---

### 2. 头面诊（面域+唇域+鼻域）—— 表里观第一视觉窗口

**拍照方法：**
- 正面免冠彩色照片，自然光下拍摄
- 须涵盖整个面部、口唇、鼻部及上颈部
- 不化妆（口红、粉底遮盖真实面色和唇色）
- 表情自然放松

**观察指标：**

| 子域 | 指标 | 枚举值 |
|:---|:---|:---|
| **面域** | 面色 | 淡白/萎黄/红赤(缘缘正赤)/红如妆(戴阳)/晦暗(寒色)/黧黑/青灰 |
| | 面部水肿 | 无/轻度浮肿/明显浮肿(面目鲜泽) |
| | 光泽 | 鲜泽/正常/晦暗枯槁 |
| **唇域** | 唇色 | 淡白/红/深红/紫暗/青紫 |
| | 唇润燥 | 润/干/燥裂/干枯 |
| | 唇周 | 正常/口周暗沉/口糜 |
| **鼻域** | 鼻色 | 正常/淡白/红赤/青黑 |
| | 鼻翼煽动 | 无/轻度/明显 |

**原文核心诊断标志（据《经方探源》）：**

| 面色表现 | 原文出处 | 病机本质 | 六病归属 | 代表方剂 |
|:---|:---|:---|:---|:---|
| **面色缘缘正赤** | L2846 | 表位郁火——卫阳郁阻在表 | **太阳病** | 麻黄汤 |
| **面有寒色（沉郁灰暗）** | L3944 | 卫阳不足，表虚寒凝 | **少阴病** | 麻黄附子甘草汤 |
| **面红如妆（戴阳）** | L3906 | 真阳欲脱，阴阳离决 | **真厥阴病** | 通脉四逆汤 |
| **面目鲜泽** | L3942 | 水饮内停，水气上浮 | **少阴伤寒+留饮** | 麻黄细辛附子汤 |
| **面色萎黄** | L1594 | 营血不足，失于荣养 | **太阴病** | 桂枝加黄芪汤 |
| **面目乍赤乍黑乍白** | L1906 | 寒热杂错，三焦不利 | **类厥阴病** | 甘草泻心汤 |
| **一身面目黄肿** | L1616 | 津液不利，水液停聚 | **太阴水病** | 甘草麻黄汤 |

**四证映射：**
- 面赤（缘缘正赤）→ **火证**（表位郁火）
- 面黄/黄肿 → **水证**（津液不化）
- 面萎黄/苍白+唇淡白 → **血证**（伤营）
- 面寒色（灰暗）→ **气证+水证**（阳虚不化）
- 唇紫暗 → **血证**（瘀血）
- 鼻翼煽动 → **气证**（肺气不利）

**鉴别诊断价值（Tier 1 — 极高）：**
- 面赤的两种鉴别：太阳"缘缘正赤"（麻黄汤） vs 戴阳"面红如妆"（通脉四逆汤）— 一表一里、一生一死
- 唇色苍白=血虚；唇色紫暗=瘀血；唇色鲜红=热盛
- 唇润燥判别津液：干裂=津亏，润=津液尚可

### 3. 目诊 —— 少阳病核心窗口

**拍照方法：**
- 近距离拍摄双眼正面，确保光线均匀
- 自然平视，不眯眼不瞪眼
- 可辅助用手指轻拉下眼睑，暴露结膜颜色

**观察指标：**

| 指标 | 枚举值 |
|:---|:---|
| 目赤 | 无/白睛微红/白睛赤丝/白睛充血 |
| 巩膜黄染 | 无/轻度/明显 |
| 眼睑浮肿 | 无/轻度(目下微肿)/明显(卧蚕)/重度 |
| 目眶黯黑 | 无/目眶黯黑/黑眼圈明显 |

**原文核心诊断标志：**

| 目诊表现 | 原文出处 | 病机本质 | 六病归属 | 代表方剂 |
|:---|:---|:---|:---|:---|
| **目赤** | L550, L2846 | 上焦郁火，卫阳郁阻 | **少阳病**（中风） | 柴胡桂枝汤 |
| **目下有卧蚕** | L3942 | 水饮内停，饮邪上犯 | **少阴+留饮** | 麻黄细辛附子汤 |
| **两目黯黑** | L1600 | 内有干血，瘀血内结 | **太阴血病** | 大黄䗪虫丸 |

**四证映射：**
- 目赤 → **火证**（上焦郁火）
- 目下有卧蚕/眼睑浮肿 → **水证**（淡饮/溢饮）
- 两目黯黑 → **血证**（瘀血/干血）

**鉴别诊断价值（Tier 1 — 极高）：**
- **目赤（少阳中风）vs 目赤（阳明里热）**：少阳目赤必兼"胸中满而烦"→ 柴胡桂枝汤；阳明目赤兼"身热汗出口燥渴"→ 白虎加人参汤
- **眼睑浮肿**（"目下有卧蚕"）= 留饮的特异性标志 → 麻黄细辛附子汤
- 巩膜黄染 + 皮肤黄如橘皮 = 急性肝胆重症（阳明水热）⚠️ 紧急就医

---

### 4. 耳诊 —— 少阳中风定向 + 津液辅助

**拍照方法：**
- 头部转向一侧约90°，露出完整外耳
- 手机从正侧面拍摄，对焦耳廓
- 光线均匀照射耳部，两侧耳朵各拍一张

**观察指标：**

| 指标 | 枚举值 |
|:---|:---|
| 耳色 | 正常/淡白/红赤/青黑 |
| 耳轮 | 润泽/干枯 |

**原文核心诊断标志：**

| 耳部表现 | 原文出处 | 病机本质 | 六病归属 | 代表方剂 |
|:---|:---|:---|:---|:---|
| **两耳无所闻** | L550 | 上焦郁火，清窍不利 | **少阳中风** | 柴胡桂枝汤 |
| **耳轮干枯** | 经方望诊 | 津液亏虚，精不上充 | **少阴/太阴**（津亏） | 视具体病机 |

**鉴别诊断价值（Tier 2 — 高）：**
- "两耳无所闻"是少阳中风四大证之一（需问诊确认）→ 柴胡桂枝汤
- 耳轮干枯=津液亏虚的重要外观标志
- 耳色淡白=血虚；红赤=热盛；青黑=寒凝/瘀血

---

### 5. 手诊 —— 六病三阴三阳快速筛选器

**拍照方法：**
- 双手并排举在胸前，掌面朝向镜头
- 手指自然微屈（不要用力绷直），指尖朝向镜头方向
- 掌面和指甲甲床同时可见
- 最好双手一起拍（便于左右对比）

**观察指标：**

| 指标 | 枚举值 | 备注 |
|:---|:---|:---|
| 手掌颜色 | 淡白/红/暗红/紫暗 | 视觉判断 |
| 手掌温度 | 温/凉/厥冷 | **由问诊获取，AI不编造** |
| 甲床颜色 | 淡白/红润/暗紫 | 视觉判断 |
| 甲床形态 | 光滑/粗糙/甲错 | 视觉判断 |
| 手掌瘀斑 | 无/散在/密集 | 视觉判断 |

**原文核心诊断标志：**

| 手足表现 | 原文出处 | 病机本质 | 六病归属 | 代表方剂 |
|:---|:---|:---|:---|:---|
| **手足温** | L2854 | 上焦郁火，阳热外达 | **少阳病** | 小柴胡汤 |
| **手足厥寒** | L3824 | 营血亏虚+寒凝 | **少阴病** | 当归四逆汤 |
| **手足厥逆（戴阳）** | L1896 | 真阳衰竭 | **真厥阴病** | 通脉四逆汤 |
| **四肢烦疼** | L1872 | 营卫俱弱，邪风虚热 | **太阴中风** | 桂枝加黄芪汤 |

**鉴别诊断价值（Tier 1 — 极高）：**
- **手足温 vs 手足厥**是六病三阴三阳鉴别的最快捷指标：
  - 手足温+渴=少阳小柴胡汤
  - 手足厥+脉细=少阴当归四逆汤
  - 手足厥逆+戴阳=真厥阴通脉四逆汤
- 甲床形态：甲错+黄汗=太阴中风（桂枝加黄芪汤）；甲错+两目黯黑=干血痨（大黄䗪虫丸）

### 6. 皮肤诊 —— 太阴中风特异性标志

**拍照方法：**
- 拍摄前臂内侧和小腿前侧（这些部位较少受日晒影响）
- 如有皮肤病灶或异常区域，单独特写
- 光线充足，避免阴影

**观察指标：**

| 指标 | 枚举值 |
|:---|:---|
| 肤色 | 正常/萎黄/黄如橘皮/黄如烟熏 |
| 甲错 | 无/局部/广泛 |
| 黄汗 | 无/可疑/明显(色正黄如柏汁) |
| 水肿 | 无/轻度凹陷/明显凹陷/全身浮肿 |
| 干燥 | 无/粗糙/龟裂 |

**原文核心诊断标志：**

| 皮肤表现 | 原文出处 | 病机本质 | 六病归属 | 代表方剂 |
|:---|:---|:---|:---|:---|
| **肌肤甲错** | L1594 | 营血不足，皮肤失养 | **太阴**（伤营） | 桂枝加黄芪汤 |
| **汗沾衣色正黄如柏汁** | L1880 | 水湿外溢，表虚不固 | **太阴中风**（黄汗） | 芪芍桂酒汤 |
| **一身面目黄肿** | L1616 | 津液不利，停而为水 | **太阴水病** | 甘草麻黄汤 |
| **肤冷（藏厥）** | L1900 | 真阳衰竭，无阳以温 | **真厥阴病** | 通脉四逆汤 |

**鉴别诊断价值（Tier 1 — 极高）：**
- **甲错辨证三角**：甲错+黄汗=太阴中风（桂枝加黄芪汤）；甲错+两目黯黑=干血痨（大黄䗪虫丸）；甲错+面萎黄=伤营（当归芍药散）
- **黄汗**是太阴中风的特异性标志 → 桂枝加黄芪汤 / 芪芍桂酒汤
- 肤色黄如橘皮+巩膜黄染=急性肝胆重症⚠️ 紧急就医

## 三、优先级分层与权重评判

### Tier 1（极高级——建议必拍）

| 维度 | 核心竞争力 | 关键鉴别 |
|:---|:---|:---|
| **舌诊** | 四证全覆盖，水火气血第一窗口 | 太阴/阳明/少阴核心判据 |
| **头面诊** | 表里寒热第一视觉指标，戴阳鉴生死 | 太阳面赤 vs 少阴戴阳——麻黄汤 vs 通脉四逆汤 |

| **皮肤诊** | 甲错/黄汗=太阴中风特异性标志 | 甲错辨证三角：桂枝加黄芪汤/大黄䗪虫丸/芪芍桂酒汤 |

### Tier 2（高级——建议条件允许时拍摄）

| 维度 | 核心竞争力 | 关键鉴别 |
|:---|:---|:---|
| **耳诊** | 少阳中风定向 + 耳轮润枯判津液 | 耳轮干枯=津亏；配合问诊听力确认少阳中风 |

## 四、标准拍照套餐建议

**基础套餐（4张，达HIGH置信度）：**
1. 舌面照 — 四证全覆盖
2. 舌底照 — 瘀血第一窗口
3. 头面部正面照 — 表里观第一关（含面+唇+鼻）
4. 双手掌面照 — 阴阳最快筛选器

**完整套餐（6张，达HIGH置信度+最高精度）：**
1. 舌面照 + 舌底照 — 舌诊
2. 头面部正面照 — 头面诊（面域+唇域+鼻域）
3. 眼部特写照 — 目诊
4. 耳部侧面照 — 耳诊
5. 双手掌面照 — 手诊
6. 前臂内侧/小腿照 — 皮肤诊

## 五、跨维度鉴别示例

**案例一：面赤的三种可能**
- 面赤（缘缘正赤）+ 手足温 + 无汗 = **太阳表郁** → 麻黄汤
- 面赤（面红如妆）+ 手足厥逆 + 汗出 = **少阴戴阳** → 通脉四逆汤
- 面赤（阵阵乍赤）+ 目赤 + 耳无所闻 = **少阳中风** → 柴胡桂枝汤

→ **仅凭头面诊无法区分三者，需要结合目诊和手诊综合判断**

**案例二：肌肤甲错的三种可能**
- 甲错 + 面萎黄 + 下睑淡白 = **太阴伤营** → 桂枝加黄芪汤
- 甲错 + 两目黯黑 + 羸瘦 = **干血痨** → 大黄䗪虫丸
- 甲错 + 黄汗 + 两胫自冷 = **太阴中风黄汗** → 芪芍桂酒汤

→ **仅凭皮肤诊无法区分，需要结合头面诊、目诊**

**案例三：手足厥的两种可能**
- 手足厥寒 + 面色尚可 = **少阴营血不足** → 当归四逆汤
- 手足厥逆 + 戴阳 + 下利清谷 = **真厥阴** → 通脉四逆汤

→ **手诊 + 头面诊可锁定病传层次**

> **核心结论**：舌诊 + 头面诊 + 目诊 + 手诊 + 皮肤诊 + 耳诊六个维度的视觉信息，配合十五项可跳过问诊，构成"拍照+问诊"的立体化辨证矩阵。其中头面诊（含面唇鼻）定表里寒热之大局，舌诊辨水火气血之核心，目诊锁定少阳/厥阴半病，手诊完成三阴三阳快速筛选，皮肤诊揭示营卫水血之虚实，耳诊辅助判津液——六者结合，在许家栋经典经方三观·四证·六病框架中实现"一份证据说一分话"的精准辨证。
