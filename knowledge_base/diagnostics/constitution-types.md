# 九种体质分类与多维判定标准（许家栋体系参照）

> 基于中华中医药学会《中医体质分类与判定》标准，结合许家栋经典经方学术体系的多维度望诊框架，建立舌诊+头面诊（面域+唇域+鼻域）+目诊+耳诊+手诊+皮肤诊六维交叉判定体系。体质判定是六病辨证的基础——体质倾向决定发病方向与传变路径。

---

## 一、体质概览与六病易感倾向

| 体质 | 六字概括 | 六病易感 | 核心病机方向 | 调理方剂方向 |
|:---|:---|:---|:---|:---|
| **平和质 (1)** | 阴阳和调 | 不易感病 | 津液输布正常 | 无需用药，饮食调摄 |
| **气虚质 (2)** | 气不足 | 太阴→少阴 | 胃气虚→里虚寒 | 甘温补气（黄芪建中类） |
| **阳虚质 (3)** | 火不足 | 少阴→厥阴 | 真阳虚→表里俱寒 | 辛甘大热（四逆汤类） |
| **阴虚质 (4)** | 水不足 | 阳明→少阴 | 津液亏虚→虚火 | 甘寒润燥（麦门冬汤类） |
| **痰湿质 (5)** | 湿有余 | 太阴（水证） | 水液代谢失常 | 甘淡利湿（苓桂术甘类） |
| **湿热质 (6)** | 湿热交蒸 | 阳明→少阳 | 水热互结→郁火 | 清热利湿（茵陈五苓类） |
| **血瘀质 (7)** | 血不行 | 厥阴→少阴 | 血行瘀滞 | 辛温活血（桂枝茯苓类） |
| **气郁质 (8)** | 气不舒 | 少阳→厥阴 | 气机升降失常 | 辛散疏利（柴胡剂类） |
| **特禀质 (9)** | 卫不固 | 太阳（表虚） | 卫外不固 | 甘平固表（玉屏风类） |

## 二、各体质多维判定标准

### 2.1 平和质（阴阳和平之人）

| 维度 | 正常指标 |
|:---|:---|
| **舌象** | 舌质淡红润泽，舌苔薄白均匀，舌体大小适中，无齿痕瘀斑 |
| **头面诊** | 面色红润光泽（"缘缘正赤"之正常面华），面部无浮肿；唇色淡红润泽，不干不燥，口周干净 |
| **目诊** | 白睛清白无赤丝，眼睑无浮肿，目眶无黯黑，目有神采 |
| **耳诊** | 耳色正常红润，耳轮润泽 |
| **手诊** | 手掌温润红活，甲床红润光滑，无瘀斑甲错 |
| **皮肤** | 肤色正常光泽，无干燥甲错，无黄汗水肿 |

> **调理方向**：无需方药。饮食有节，起居有常，不妄作劳。

---

### 2.2 气虚质（太阴里虚——胃气虚方向）

| 维度 | 典型表现（≥3项可判定） |
|:---|:---|
| **舌象** | 舌质淡嫩，舌体胖大边有齿痕，苔薄白或白滑 |
| **头面诊** | 面色萎黄少华或淡白无泽，面部肌肉松弛；唇色淡白，唇周松软 |
| **目诊** | 眼睑轻度浮肿（下睑松软），目无神采，不耐久视 |
| **耳诊** | 耳色淡白，耳轮偏枯 |
| **手诊** | 手掌淡白松软，皮肤温度偏凉，甲床淡白 |
| **皮肤** | 皮肤松弛，易出汗（自汗），肌肉松软不实 |

> **六病易感**：太阴→里虚寒方向，易从理中汤/黄芪建中汤路径发展
> **调理方剂方向**：甘温补气——黄芪建中汤类（炙黄芪+桂枝汤倍芍药+饴糖）、补中益气汤类
> **核心药组方向**：黄芪、党参、白术、炙甘草、大枣

---

### 2.3 阳虚质（少阴里寒——真阳虚方向）

| 维度 | 典型表现（≥3项可判定） |
|:---|:---|
| **舌象** | 舌质淡白或淡胖，苔白滑或水滑，舌体胖大明显，齿痕深 |
| **头面诊** | 面色淡白无华或晦暗（寒色），面部有轻度浮肿；唇色淡白甚至青紫，口淡不渴 |
| **目诊** | 白睛清白偏冷色调，下眼睑浮肿（卧蚕明显），目无神 |
| **耳诊** | 耳色淡白或青灰，耳轮干枯 |
| **手诊** | 手足厥冷（持续），手背凉，甲床淡白或青紫 |
| **皮肤** | 皮肤触之冰冷（肤冷），皮肤松弛无弹性，肤色苍白 |

> **六病易感**：少阴（两层病位——表虚寒+真阳虚），可进展至真厥阴
> **调理方剂方向**：辛甘大热回阳——四逆汤类、通脉四逆汤类、真武汤类
> **核心药组方向**：附子、干姜、炙甘草、肉桂
> ⚠️ **关键鉴别**：手足持续厥冷是阳虚质区分气虚质的最关键指标（气虚为"凉"，阳虚为"厥"）

---

### 2.4 阴虚质（阳明津亏——虚火方向）

| 维度 | 典型表现（≥3项可判定） |
|:---|:---|
| **舌象** | 舌质红绛偏干，舌体瘦小，苔少或无苔（镜面舌倾向），有裂纹 |
| **头面诊** | 面色偏红（颧部潮红为主），皮肤干燥少泽，面形偏瘦；唇色深红偏干，口干欲饮，唇可干裂 |
| **目诊** | 白睛微红，目干涩，眼干易疲劳 |
| **耳诊** | 耳色偏红，耳轮偏干 |
| **手诊** | 手足心热（五心烦热），手掌偏红，甲床干燥少泽 |
| **皮肤** | 皮肤干燥粗糙甚至龟裂，弹性差，皮肤偏热 |

> **六病易感**：阳明→津伤燥热方向，可进展至少阴热化证
> **调理方剂方向**：甘寒润燥——麦门冬汤类、百合地黄汤类、芍药甘草汤类
> **核心药组方向**：麦冬、百合、生地黄、白芍、甘草

---

### 2.5 痰湿质（太阴水证——水液代谢失常）

| 维度 | 典型表现（≥3项可判定） |
|:---|:---|
| **舌象** | 舌质淡胖边有齿痕，苔白厚腻或白滑腻，舌体胖大 |
| **头面诊** | 面色淡白发暗，面部轻度浮肿（面目鲜泽），油脂分泌多；唇色淡白偏润，口粘不爽 |
| **目诊** | 下眼睑浮肿（卧蚕），白睛微浊 |
| **耳诊** | 耳色淡白偏润，耳轮润泽 |
| **手诊** | 手掌偏湿粘，手掌偏凉，轻微浮肿感 |
| **皮肤** | 皮肤油腻，汗出粘腻，可有轻度凹陷水肿 |

> **六病易感**：太阴（水证——里虚寒+水饮），可发展为太阴中风
> **调理方剂方向**：甘淡利湿——苓桂术甘汤类、五苓散类
> **核心药组方向**：茯苓、桂枝、白术、泽泻、薏苡仁

---

### 2.6 湿热质（阳明水热——太阴湿热方向）

| 维度 | 典型表现（≥3项可判定） |
|:---|:---|
| **舌象** | 舌质偏红，苔黄腻，舌体可胖大 |
| **头面诊** | 面色偏黄（黄如橘皮），面部油光，易生痤疮；唇色红偏干，口苦口臭，口粘 |
| **目诊** | 白睛微黄或浑浊，眼眵增多，目赤 |
| **耳诊** | 耳色偏红，耳轮润泽或油腻 |
| **手诊** | 手掌湿热偏红或有汗疱疹，掌温偏热 |
| **皮肤** | 皮肤黄如橘皮（黄疸指征），湿疹瘙痒，黄汗倾向 |

> **六病易感**：阳明→水热互结，可传少阳（湿热郁火）
> **调理方剂方向**：清热利湿——茵陈蒿汤类、栀子柏皮汤类
> **核心药组方向**：茵陈、栀子、大黄、茯苓、泽泻、薏苡仁

---

### 2.7 血瘀质（厥阴/少阴血证——血行瘀滞）

| 维度 | 典型表现（≥3项可判定） |
|:---|:---|
| **舌象** | 舌质紫暗或有瘀斑瘀点，舌下络脉迂曲增粗色紫黑 |
| **头面诊** | 面色晦暗（寒色偏暗）或黧黑，面色不泽；唇色紫暗或青紫，口周暗沉 |
| **目诊** | 两目黯黑（目眶黯黑如烟熏），白睛可有血丝 |
| **耳诊** | 耳色暗红或青紫，耳轮可有瘀点 |
| **手诊** | 手掌暗红或紫暗，甲床紫暗或有甲错，手掌瘀斑 |
| **皮肤** | 肌肤甲错（皮肤粗糙如鱼鳞），皮下瘀斑，肤色暗沉 |

> **六病易感**：厥阴→血分病，可发展为干血痨（大黄䗪虫丸证）
> **调理方剂方向**：辛温活血——桂枝茯苓丸类、当归芍药散类、大黄䗪虫丸类
> **核心药组方向**：当归、川芎、赤芍、桃仁、桂枝、茯苓

---

### 2.8 气郁质（少阳→厥阴方向——气机失常）

| 维度 | 典型表现（≥3项可判定） |
|:---|:---|
| **舌象** | 舌质淡红或稍暗，苔薄白或薄黄，舌形偏尖 |
| **头面诊** | 面色乍赤乍白（阵发性），面色可正常或偏暗；唇色可正常，口苦（少阳提纲证），口干咽干 |
| **目诊** | 目赤时作时止（郁火上冲），目眶颜色可正常 |
| **耳诊** | 耳色正常或乍赤乍白（阵发性） |
| **手诊** | 手足时温时凉（情绪波动影响四末温度），手掌颜色可正常 |
| **皮肤** | 皮肤一般正常，可因气滞出现局部敏感或荨麻疹 |

> **六病易感**：少阳→上焦郁火+中焦胃虚，可传厥阴（寒热杂错）
> **调理方剂方向**：辛散疏利——小柴胡汤类、四逆散类、逍遥散类
> **核心药组方向**：柴胡、枳壳、白芍、甘草、薄荷、香附

---

### 2.9 特禀质（太阳表虚——卫外不固）

| 维度 | 典型表现（≥3项可判定） |
|:---|:---|
| **舌象** | 舌质淡红或偏淡，苔薄白，舌体可偏胖 |
| **头面诊** | 面色淡白或时作面部风团（荨麻疹），面部可有过敏表现；唇色正常或偏淡，口周可有过敏表现 |
| **目诊** | 目痒流泪（过敏性结膜炎），眼睑可浮肿 |
| **耳诊** | 耳色淡白或正常，耳轮正常或偏干 |
| **手诊** | 手掌可正常，甲床可正常 |
| **皮肤** | 皮肤敏感，遇风冷即起风团（瘾疹），鼻炎/哮喘倾向 |

> **六病易感**：太阳（表虚——卫气不固），可有太阴倾向
> **调理方剂方向**：甘平固表——玉屏风散类、桂枝加黄芪汤类
> **核心药组方向**：黄芪、白术、防风、桂枝、白芍、甘草

## 三、体质与六病易感的辨证路径

### 3.1 体质→六病映射逻辑

```
平和质 → 不易感病（正气存内，邪不可干）
气虚质 → 太阴里虚 → 邪入从寒化 → 太阴→少阴传变
阳虚质 → 少阴里寒 → 感邪即入阴 → 少阴→厥阴传变
阴虚质 → 阳明津亏 → 邪入从热化 → 阳明→少阴热化
痰湿质 → 太阴水证 → 感邪从湿化 → 太阴水病
湿热质 → 阳明水热 → 感邪从湿热化 → 阳明→少阳水热
血瘀质 → 血分已病 → 感邪加重血瘀 → 厥阴血证
气郁质 → 少阳枢机不利 → 感邪郁而化火 → 少阳→厥阴
特禀质 → 太阳表虚 → 感邪即中表 → 太阳表证反复
```

### 3.2 体质判定注意事项

1. **主体质+兼夹体质**：多数人存在混合体质（如气虚+痰湿、阴虚+血瘀），应标注主体质和兼夹体质
2. **体质可动态变化**：随季节、年龄、疾病状态而变化，建议每季度重新评估
3. **多维交叉验证**：判定体质需至少3个维度一致指向，单维度不构成判定
4. **舌诊权重最高**：舌象是体质判定中权重最高的维度（"舌为五脏之外候"）
5. **头面诊鉴别寒热方向**：面色寒热是区分气虚→阳虚方向的关键鉴别点
