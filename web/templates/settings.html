视觉模型

识图 · 七部位照片分析 {% if 'VISION_DISABLED' in env_locked %}（环境变量锁定）{% endif %}

作用：把七部位照片（舌面/舌底/头面/目/耳/手/皮肤）判读为结构化观察值——系统的数据入口。 未配置或在下方关闭时，拍照页改用手动录入模式（肉眼观察后逐项选择，评分/红线/趋势照常由本地引擎完成）。 需用具备图像理解能力的多模态视觉模型。

{{ secret_input("VISION_API_KEY", "sk-…") }}
环境变量 VISION_API_KEY · 当前来源：{{ values["VISION_API_KEY"].source }}
VISION_BASE_URL · 必须是 OpenAI 兼容的 chat/completions 完整地址（形如 https://…/v1/chat/completions）；Anthropic 协议端点不支持；缺 /chat/completions 后缀时 Web 层会自动补齐（命令行脚本 vision_client.py 不规整，直接用脚本时请填全）{% if 'VISION_BASE_URL' in env_locked %} · 来自环境变量，页面不可改{% endif %}
VISION_MODEL · 任意 OpenAI 兼容视觉模型；先填端点再点「获取列表」从端点拉取可选模型；换模型后需重新标定封闭词表
VISION_TEMPERATURE · 控制模型输出的随机性：越低措辞越稳定，越高越发散。推荐留空（不发送该参数，由模型默认值生效）；注意部分端点有服务端下限（如 DashScope 钳制到 0.6，设 0 也按 0.6 算）
VISION_TIMEOUT · 推荐 150–300：识图是大请求（照片 base64 + 结构化输出），过短会中途超时失败；思考型模型取大些。留空则用代码默认 150
